# AI Course Platform

基于知识图谱 + LLM 的 AI 助教系统。

当前项目为全新独立实现，旧项目只作为业务需求、表结构和历史问题参考。后端持久层统一采用 MyBatis-Plus，不使用 JPA。

## 技术栈

- 后端：Spring Boot 3.2.0、Java 17、MyBatis-Plus、Spring Security、JWT、MySQL、Redis
- 前端：Vue 3、Vite、Element Plus、Pinia
