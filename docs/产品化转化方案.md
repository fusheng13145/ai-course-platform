## 1. 形态可行性评估（独立软件 / 网站 / 小程序）

| 形态 | 可行性 | 适用场景 | 复用度 / 改造量 | 结论 |
| --- | --- | --- | --- | --- |
| 多租户 Web SaaS（网站） | ★ 可行（最优） | 高校 / 培训机构多租户教学、社会培训、个人自学订阅 | 后端逻辑复用 80%+；需加租户隔离 / 计费 / 配额；flowcontrol 可扩为租户配额 | **主形态** |
| 微信小程序 | 可行 | C 端轻触达：查课表 / 成绩 / 刷题 / 通知；重考试防作弊不适合 | 后端 REST 复用；前端 uni-app / Taro 重写；加 code2session 桥接、临时文件上传、订阅消息；HttpOnly Cookie → 小程序登录态 + Bearer | **轻量入口** |
| 桌面软件（独立软件） | 可选（低优先） | 高校内网一体机（离线 / 内网管控） | Tauri 打包前端 Vue + 内网后端；考试 / AI 判分 / 防作弊强依赖服务端，离线价值低 | 非首选 |

**判定**：以「多租户 Web SaaS 为主形态 + 微信小程序为轻触达渠道」；桌面软件仅在特定内网场景作为可选交付。

### 优劣对比

- **Web SaaS**：开发成本最低（复用现有 Spring Boot + Vue）、分发最易（URL + 子域名）、易做多租户与计费；劣势是需自建运维 / 合规 / 客服体系。
- **微信小程序**：触达成本低（微信生态）、适合轻量学习；劣势是平台审核约束、不能承载重考试防作弊、需额外登录态改造（F-19）。
- **桌面软件**：满足内网 / 离线管控；劣势是离线价值低（核心 AI / 判分 / 防作弊依赖服务端）、分发与升级成本高。

## 4. 整体架构（多租户改造）

4.1 **数据层**：行级隔离 `tenant_id` + 租户上下文拦截器（MyBatis `TenantLineInnerInterceptor` 自动注入）；schema 隔离为备选（依合规 / 规模定）。
4.2 **认证层**：API 网关签发 **tenant-scoped JWT**（claim 含 tenantId）；小程序走微信 `code2session` 换自有 token，弃 HttpOnly Cookie 单租户假设。
4.3 **部署**：K8s + RDS(MySQL) + 对象存储（MinIO / OSS）；配额复用 Sentinel(flowcontrol)。
4.4 **复用**：Spring Boot + Vue 不变；Python KG / RAG 微服务保持契约对接（手册第八部分）。
4.5 **小程序端**：uni-app 重写轻端；临时文件上传 + 订阅消息；重考试防作弊仍在 Web 端。

> ⚠️ 当前代码库为**单租户**（全仓 `grep tenant` 零命中），M1 多租户隔离为**从零引入**，工期与优先级最高（见第 6 节安全验收）。

## 5. 安全验收门槛（产品化高优先级，来自 2026-09-14 安全审计交叉增补）

- **F-18（🔴）多租户隔离**：`TenantLineInnerInterceptor` 全局注入 + `tenantId` claim 强制 + 缓存 key 加租户前缀 / 命名空间隔离（与 F-17 缓存跨租户泄露合并为**单一工作项**）。任一遗漏 = 跨租户越权，M1 必须验收通过。
- **F-19（🟠）小程序 token 改造**：`session_key` 绝不下发 / 入日志；自有 Bearer 短 TTL 绑 openid；微信 `access_token` 仅服务端持有。任一遗漏 = 中-高伪登录 / 越权，M3 验收。
- 其余既有项（F-01 静态资源 ACL、F-02 密钥治理、F-09 XSS、F-14 CORS）按上线前检查行动清单继续执行。

## 6. 开发规划路线

- **M1 多租户数据隔离 + 租户上下文（最高优先级，从零引入）**
  - `TenantLineInnerInterceptor` + `tenant_id` 行级；租户上下文拦截器 / ThreadLocal。
  - 缓存租户隔离（F-17 / F-18 合并工作项）。
  - 单测固化隔离与跨租户拒绝。
  - **安全验收：F-18 通过。**
- **M2 认证 / 计费 / 配额**
  - 网关 tenant-scoped JWT；小程序 `code2session` 桥接（F-19 验收）。
  - 配额复用 flowcontrol(Sentinel)；计费台账。
- **M3 微信小程序轻端**
  - uni-app 重写；课表 / 成绩 / 刷题 / 通知；临时文件上传 + 订阅消息。
  - **安全验收：F-19 通过。**
- **M4 桌面一体机（可选）**
  - Tauri 内网打包前端 + 内网后端；离线管控场景。
