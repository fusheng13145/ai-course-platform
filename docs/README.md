## 4. 维护约定（防止再次膨胀）

- **不新增第 11 份文档**：新主题先写进对应主文档的章节；确需独立文件时，先确认它不会变成下一份"一次性记录"。
- **不建归档目录**：验收、演练、诊断、评估类的一次性记录，写完即把**结论**并入对应主文档，原稿不入库。
- **引用禁行号**：文档之间用章节名或条目编号（DR-xx / R-xx / FE-xx / D-x / AG-x）。
- **数字只写一处**：结构性计数在项目手册 §8，测试读数在测试文档 §2，需求状态在 PRD §14.2，未完成项在各待办项。
