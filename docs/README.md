## 6. 维护约定

- **归档来源**：早期过程稿（后端信息架构 10 条决策、**组织映射清单 D1–D10**、WP 拆包、消息队列评估）已并入 [系统架构设计 §4/§6](./系统架构设计.md)，原文不再保留。
- **新增文档必须同步本索引**：更新 §2/§3/§4 的清单与顶部规模；不得出现“文件已建、索引未记”。
- **数字只写一处**：结构性计数在项目手册 §8，测试读数在测试文档 §2，剩余任务状态在当前状态与待办总表，需求状态在 PRD §14.2。
- **引用禁行号**：文档之间用章节名或条目编号（DR-xx / R-xx / FE-xx / D-x / AG-x）。
- **学术表达**：事实、推断、未取证三分；引用数字必须带时点、口径与可重放命令；不得用“已实现／已达标”等结论替代证据。
- **时间戳证据文档**：只追加当期实测，不回头篡改历史读数；结论变化写入总表并在证据文档顶部标注“已被取代”。
- **一次性记录不入库**：验收、演练、诊断类过程稿写完把结论并入主文档；确需保留原文时放 `docs/archive/` 并同步索引。
