# 升级前 a11y 基线（2026-10-21，控制器取数）—— §6.2 "只降不升"的起点

**这是什么**：spec §6.2 要"axe 违规数 ≤ 升级前基线"。本仓 **Phase 0 不引入 `@axe-core/playwright`**
（会与新依赖约束冲突，裁定记在计划 Task 15 的"有意留下的缺口"里），所以这格由控制器
用浏览器工具取**近似读数**，**不是自动门**，也不与 axe 的规则集等价。引用它时必须带这句限定。

**取数方式（可重放）**：起 dev server（`cd frontend && npm run dev -- --port 5175 --strictPort`），
用 `admin / 123456`（db/migration 里的种子演示账号，非秘密）登录后打开目标页，
把下面这段脚本粘进控制台执行，返回的就是本文各表的数。它只做四件事：
小字号文本对比度、无无障碍名的表单/按钮、重复 id、`img` 缺 `alt`。

```js
// 近似算法（已知盲区见文末"这台尺量不到什么"）
const parse = s => (s.match(/-?\d+(\.\d+)?/g) || []).slice(0, 3).map(Number);
const lum = c => { const v = c.map(x => (x /= 255, x <= 0.03928 ? x / 12.92 : Math.pow((x + 0.055) / 1.055, 2.4))); return 0.2126 * v[0] + 0.7152 * v[1] + 0.0722 * v[2]; };
const ratio = (a, b) => (Math.max(lum(a), lum(b)) + 0.05) / (Math.min(lum(a), lum(b)) + 0.05);
const accName = el => (el.getAttribute('aria-label') || el.getAttribute('title') ||
  (el.id && document.querySelector(`label[for="${el.id}"]`)?.textContent) ||
  el.closest('label')?.textContent || el.textContent || '').trim();
const bgOf = el => { let e = el; while (e) { const b = getComputedStyle(e).backgroundColor; if (b && !/rgba\(0, 0, 0, 0\)|transparent/.test(b)) return parse(b); e = e.parentElement; } return [255, 255, 255]; };
let low = 0, vis = 0, worst = 99, sample = '';
for (const el of document.querySelectorAll('body *')) {
  if (el.children.length || !(el.textContent || '').trim()) continue;
  const cs = getComputedStyle(el); if (cs.display === 'none' || cs.visibility === 'hidden') continue;
  const r0 = el.getBoundingClientRect(); if (!r0.width || !r0.height) continue; vis++;
  const fs = parseFloat(cs.fontSize) || 16, fw = parseInt(cs.fontWeight) || 400;
  if (fs >= 18.66 || (fs >= 14 && fw >= 700)) continue;         // 大字走 3:1，本轮不判
  const r = ratio(parse(cs.color), bgOf(el));
  if (r < 4.5) { low++; if (r < worst) { worst = r; sample = `${el.tagName}.${el.className}`; } }
}
const ids = new Set(), dup = new Set();
for (const e of document.querySelectorAll('[id]')) { if (ids.has(e.id)) dup.add(e.id); ids.add(e.id); }
const inputs = [...document.querySelectorAll('input:not([type=hidden]),textarea,select')];
const clickables = [...document.querySelectorAll('button,a[href]')];
({ url: location.pathname, visibleTextLeaves: vis, smallTextUnder45: low,
   worstRatio: +worst.toFixed(2), worstSample: sample,
   inputMissingName: inputs.filter(i => !accName(i)).length, inputsTotal: inputs.length,
   clickableMissingName: clickables.filter(c => !accName(c)).length, clickablesTotal: clickables.length,
   dupIds: dup.size, imgMissingAlt: [...document.querySelectorAll('img')].filter(i => !i.hasAttribute('alt')).length });
```

## 两处必须写进基线的读数纠正（不写就等于把伪读数传给下一批）

1. **`worstRatio 1.00` 是这台尺的伪读数，不是页面的真实最差值。**
   它命中 `SPAN.avatar`（表格里"管理员"首字），脚本按 `backgroundColor` 逐级上溯找底色，
   而该元素的底色是 **`linear-gradient(135deg, #b57908, #8a5d06)`**、自身 `backgroundColor` 透明 ⇒
   脚本抓到了祖先的近黑色 `rgb(23,29,38)`，与文字色同值，于是算出 1.00。
   控制器按真实梯度两端手工重算（文字色 `#171D26`）：**浅端 `#B57908` ≈ 4.60:1（勉强过 4.5），
   深端 `#8A5D06` ≈ 2.94:1（不过）**。⇒ 缺陷是真的（渐变末端的 13–14px 首字不达 4.5），
   但**数值必须用重算后的 2.94**，用 1.00 会把这条夸大成"完全不可见"。
2. `/login` 那 5 处小字最低 **1.14:1** 是**真读数**：`P.brand-sub` 的 `rgb(107,116,136)` 压在
   `rgb(193,59,48)` 这块赭红品牌底上，脚本抓到的就是实际底色，控制器按 WCAG 公式复算同为 1.14。

## 这台尺量不到什么（下一批不许把它当 axe 用）

渐变与图片背景（见上）、`::before`／`::after` 生成的文字、纯图标按钮的**名是否达意**（只查有没有名）、
焦点可见性（键盘走查属 §6.16）、`aria-*` 值合法性、地标与标题层级、以及 axe 规则集里的另外几十条。
⇒ **§6.2 的"axe 违规数 ≤ 升级前基线"这条在本批只能降级为"上表四类读数不升"**；
要机器证明必须 Phase 1 批准装 `@axe-core/playwright` 并把这四页纳入基线（届时**重新取一次数**，别拿本文当 axe 基线）。
