
### 路径② 直接 SQL 注入（绕过缺陷接口，保证链路可验证）

本轮因 R-01 导致资源上传接口不可用，资源数据以 SQL 直插准备（等价方式，已在报告中标注）：
```sql
INSERT INTO resources (file_name, file_type, url, course_id, chapter_id, uploader_id, description, visible_to_all)
VALUES ('网络概述.mp4','video/mp4','/uploads/e2e-video.mp4', :cid, :ch1, 2, '第1章 教学视频', 1),
       ('第1章讲义.pdf','application/pdf','/uploads/e2e-doc.pdf', :cid, :ch1, 2, '第1章 讲义', 1);
```
> 若走此路径验证「下载」环节，必须把文件真实落到 `backend/uploads/` 对应文件名，否则 `GET /resources/download/{id}` 会返回 404（本轮 H3 即因文件缺失返回 404，属数据准备问题而非接口缺陷）。

### 路径③ 通过 API 构造（推荐，语义最真实）

**建课**（注意日期为 **ISO-8601**）：

**章节 → 作业 → 题目 → 组卷**：

```json
POST /api/questions/create

```

**考试作答（答案键 = questionId，值为普通字符串）**：
```json
POST /api/exam-sessions/start        {"examPaperId": {pid}}
POST /api/exam-sessions/{sid}/auto-save  {"sessionId": {sid}, "answers": {"10":"B","11":"B","12":"false"}}
POST /api/exam-sessions/{sid}/submit     {"sessionId": {sid}, "answers": {"10":"B","11":"B","12":"false"}}
```

### 数据准备的三条硬性注意（实测踩坑，务必遵守）

| # | 注意 | 依据 |
|---|------|------|
| 1 | **`LocalDateTime` 入参必须 ISO-8601**（`2026-09-14T16:00:00`）。用 `application.yaml` 声明的 `yyyy-MM-dd HH:mm:ss` 会得到 400「请求格式错误」 | `spring.jackson.date-format` 只作用于 `java.util.Date`；实测 course/task 日期字段 |
| 2 | **`questions.type` 必须大写**（SINGLE_CHOICE / MULTIPLE_CHOICE / TRUE_FALSE / SHORT_ANSWER / FILL_BLANK），且 `auto-compose.typeRules` 的键须与存量值完全一致，否则**静默选出 0 题**（不报错） | 实测：小写键导致组卷题数 0 |
| 3 | **`questions.correct_answers` 是 JSON 列**，单值需写成 `"\"B\""`（JSON 字符串）；该存储形态正是 R-04 判分恒错的根因 | DB 实测值 `"B"` |

## 三、主链路逐环节验证（验证要点 / 预期 / 判定标准 / 落库断言）

> 「实测」列取自本轮真实执行结果；「判定标准」为该环节的客观通过判据。

### 环节1 教师创建课程

| 项 | 内容 |
|----|------|
| 操作路径 | 前端 `/teacher/courses/create` → `POST /api/teacher/courses` |
| 前置 | TEACHER 登录；`courses.code` 未占用 |
| 验证要点 | ①仅 TEACHER/ADMIN 可建 ②`teacher_id` 自动绑定当前登录教师 ③初始 `approval_status=PENDING`、`status=active` ④`code` 唯一 |
| 预期结果 | 200；`code` 唯一冲突时拒绝 |
| 判定标准 | HTTP 200 + `data.teacherId == 当前用户`；DB `approval_status='PENDING'` |
| 落库断言 | `SELECT approval_status,status,teacher_id FROM courses WHERE code='CS-NET-2026';` → `PENDING / active / 2` |
| 实测 | ✅ 通过（B1/B2）。⚠️ 边界 B3：重复 code 返回 **500**（DB 唯一约束异常直冒，未转 400）→ R-07 |

### 环节2 管理员审核通过

| 项 | 内容 |
|----|------|
| 操作路径 | `/admin/courses` → `POST /api/courses/{id}/approve`（或 `/reject`） |
| 前置 | ADMIN 登录；课程存在且为 PENDING |
| 验证要点 | ①仅 ADMIN 可审批 ②通过后 `approval_status=APPROVED` 且 `status=ACTIVE` ③驳回写 `approval_comment` ④**PENDING 课程不应对学生开放** |
| 预期结果 | 200；TEACHER/STUDENT 调用 → 403；PENDING 课程不可选课 |
| 判定标准 | `@PreAuthorize hasRole('ADMIN')` 生效 + DB 双字段同步翻转 |
| 落库断言 | `SELECT approval_status,status FROM courses WHERE id={cid};` → `APPROVED / ACTIVE` |
| 实测 | ✅ 审批通过（C4/C5）、教师越权 403（C3）。❌ 学生越权返回 **401**（应为 403，C2→R-07）；❌ **PENDING 课程可被选课**（C1→R-05） |

### 环节3 教师上传资料与视频

| 项 | 内容 |
|----|------|
| 操作路径 | `/teacher/courses/:id` → `POST /api/resources/upload`（multipart: `file`,`courseId`,`description`）；可见性 `PATCH /api/resources/{id}/visibility` |
| 前置 | TEACHER 且为课程归属人 |
| 验证要点 | ①白名单类型（pdf/doc/docx/xls/xlsx/jpg/png/gif/**mp4**/mp3）②**魔数校验**（防伪装）③空文件拒绝 ④≤50MB ⑤落库 `resources` 且 `visible_to_all` 可控 |
| 预期结果 | 200 + 返回 `resource.id/url`；空/伪装/非法类型 → 400 业务错误；超限 → 413/400 |
| 判定标准 | 200 且 `resources` 新增一行；`file_type` 与声明一致 |
| 落库断言 | `SELECT file_name,file_type,course_id,visible_to_all FROM resources WHERE course_id={cid};` |
| 实测 | ❌ **有效上传恒定 500**（D3/D5）→ **R-01（P0）**；❌ 可见性切换 500（D10）→ 同源 R-01；❌ 超限 500（D9）→ R-07；✅ 空文件/伪装/非法类型均被正确拒绝（D6/D7/D8）；✅ 对照接口 `/api/common/upload` 正常（D5b，界定故障范围） |

### 环节6 学生加入课堂（选课）

|----|------|

### 环节9 学生参加考试

| 项 | 内容 |
|----|------|
| 操作路径 | `POST /api/exam-sessions/start` → `GET /{id}/questions` → `POST /{id}/auto-save` → `POST /{id}/submit` → `POST /{id}/auto-grade` → `GET /{id}/result` |

| 实测 | ✅ 开考/取题/自动保存/交卷/重复交卷拦截/超次数拦截/查询成绩/他人会话 403 通过（J2–J6、J8–J12）。❌ **未选课学生可直接开考**（J1→R-05）；❌ **全对作答得分 0.00**（J7→R-04）；❌ **进行中的考试被调度器 40s 内强制收卷**（J13→R-02） |
