## 1. 项目概述

### 1.1 项目简介
AI智能课程平台是一套基于Spring Boot + MyBatis-Plus + Vue 3的智能在线教育系统，面向高校和培训机构，提供课程管理、在线考试、知识图谱、AI辅助学习等全流程功能。支持管理员、教师、学生三种角色协同工作。

### 1.2 核心目标
- **基础能力**：用户注册登录、多角色权限隔离、课程全生命周期管理
- **AI赋能**：集成大模型能力，提供智能出题、学情分析、学习路径推荐、智能问答
- **体验优化**：Element Plus UI，ECharts可视化，响应式操作流程
- **实时通信**：WebSocket实时通知推送

### 1.3 参考项目
本项目基于开源项目 [ai-smart-course-platform](https://github.com/Lllxy11/ai-smart-course-platform) 进行二次开发，技术栈从JPA迁移至MyBatis-Plus，并完成了功能增强和优化。

## 4. 系统架构

```
┌─────────────────────────────────────┐
│         Client (Vue 3 SPA)          │
│  localhost:5173 → proxy → /api      │
└────────────────┬────────────────────┘
                 │ RESTful API (JWT Auth)
                 │ WebSocket (ws://)
┌────────────────▼────────────────────┐
│    Backend (Spring Boot 3.5)        │
│  ┌──────────────────────────────┐   │
│  │  Controller Layer (22个)     │   │
│  ├──────────────────────────────┤   │
│  │  Service Layer (50+个)      │   │
│  ├──────────────────────────────┤   │
│  │  Mapper Layer (30+个)        │   │
│  ├──────────────────────────────┤   │
│  │  WebSocket Handler           │   │
│  └──────────────────────────────┘   │
└────────────────┬────────────────────┘
                 │
┌────────────────▼────────────────────┐
│      MySQL 8.0 (32 tables)          │
│      Redis (Session/Cache)          │
└─────────────────────────────────────┘
```

### 权限控制流程
```
Request → JwtRequestFilter → 解析JWT Token
  → SecurityContextHolder.setAuthentication
  → SecurityFilterChain 验证角色
  → Controller 处理请求
  → GlobalExceptionHandler 统一异常处理
  → ApiResponse 统一响应格式
```

## 13. Redis启动说明

Redis 用于会话缓存和性能优化，非必需启动。当前项目配置为可选启动。

### 不启动Redis的影响
- 应用仍可正常启动和运行
- 会话管理将使用数据库存储（user_sessions表）
- 部分缓存功能（如验证码存储）不会生效
- 不影响登录、课程管理、考试等核心业务功能

### Windows本地启动Redis
```bash
# 方式1：使用Windows版Redis
redis-server

# 方式2：使用WSL
wsl redis-server

# 方式3：使用Docker
docker run -d -p 6379:6379 redis:7
```

### Linux/Mac启动Redis
```bash
redis-server
```

## 14. 热部署配置说明

### 后端热部署 (Spring Boot DevTools)

**配置文件**: `backend/pom.xml` 和 `backend/src/main/resources/application.yaml`

```yaml
# application.yaml
spring:
  devtools:
    restart:
      enabled: true
      additional-paths: src/main/java
    livereload:
      enabled: true
```

**使用方式**: 修改Java代码后，保存文件会自动重启应用。

### 前端热更新 (Vite HMR)

**配置文件**: `frontend/vite.config.js`

```javascript
server: {
  hmr: {
    overlay: true,
    wait: 1000
  },
  watch: {
    usePolling: true,
    interval: 100
  }
}
```

**使用方式**: 修改Vue/JS/CSS文件后，浏览器自动热更新。
