## 1. 项目概述

### 1.1 项目定位

本项目针对专业课程教学知识碎片化、个性化学习支持不足、大语言模型存在知识幻觉等行业痛点，融合知识图谱与大语言模型技术，以《计算机网络》专业课程为试点，构建基于检索增强生成（RAG）框架的 AI 助教系统。

### 1.2 核心功能

- **智能问答**：RAG 增强专业问题解答，降低知识幻觉
- **知识图谱**：知识点关联可视化，学习路径规划
- **学情分析**：教师/学生双视角，AI 自动生成建议
- **个性化学习**：错题本、学习日历、薄弱点诊断
- **课程管理**：课程 CRUD、章节管理、选课审批
- **作业考试**：AI 智能出题、作业批改、模拟考试

## 4. 部署指南

### 4.1 环境要求

| 环境      | 版本要求    |
| ------- | ------- |
| Java    | JDK 17+ |
| Node.js | v18+    |
| MySQL   | 8.0+    |
| Maven   | 3.8+    |

### 4.2 后端部署

```bash
# 1. 配置环境变量
cp backend/.env.example backend/.env
# 编辑 .env 文件，配置数据库连接和 DeepSeek API Key

# 2. 编译项目
cd backend
./mvnw clean package -DskipTests

# 3. 运行
java -jar target/ai-course-platform-0.0.1-SNAPSHOT.jar
```

### 4.3 前端部署

```bash
# 1. 安装依赖
cd frontend
npm install

# 2. 构建生产版本
npm run build

# 3. 部署到 Nginx
cp dist/* /var/www/html/
```

### 4.4 Docker 部署（推荐）

```bash
# 构建镜像
docker build -t ai-course-platform .

# 运行容器
docker run -d -p 8080:8080 -p 5173:5173 ai-course-platform
```

## 5. 配置说明

### 5.1 环境变量配置（backend/.env）

```properties
# 数据库配置
DB_URL=jdbc:mysql://localhost:3306/ai_course?useSSL=false&serverTimezone=Asia/Shanghai
DB_USERNAME=root
DB_PASSWORD=your_password

# DeepSeek API 配置
DEEPSEEK_API_KEY=your_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com

# JWT 配置
JWT_SECRET=your_jwt_secret_key
JWT_EXPIRATION=86400000

# Python 微服务配置（预留）
GRAPH_SERVICE_URL=http://localhost:8001
RAG_SERVICE_URL=http://localhost:8002
FINE_TUNE_SERVICE_URL=http://localhost:8003
```

### 5.2 前端配置（frontend/.env）

```properties
VITE_API_BASE_URL=http://localhost:8080/api
VITE_APP_TITLE=AI助教系统
```
