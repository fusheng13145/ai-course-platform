## 3. 导航层级（硬约束）

### 3.1 学生端最外层

只保留 **我的课程 / 系统消息 / 学业档案 / 工作台**。

- 作业、课件、讨论、成绩、考试、知识图谱、AI 助教等，全部归属到具体课程之下。
- 学业档案是跨课程汇总页；课程成绩、学习路径、薄弱点仍在课程内。
- 工作台是待办与快捷入口，不复制课程内功能页。

### 3.2 教师端最外层

只保留 **我的课程 / 系统消息 / 工作台**。

- 课程建设、章节、作业、课件、讨论、成绩、考试、监考、知识图谱、AI 助教、AI 语料，全部在课程空间内。
- 在线监考并入考试页，不单独占外层入口。
- AI 语料并入 AI 助教（页面标题统一“AI 助教”），不单独占外层入口。
- 管理端治理入口只在管理员角色可见，不混入教师外层导航。

### 3.3 路由与页面

- 一页 = `PageHead(title)` + 动作 + 内容；页头不写副标题、kicker、来源章。
- 外层导航不出现课程内动作；课程内页不重复外层全局入口。
- 面包屑只在课程空间内表达“课程 → 章节/页面”，不跨角色。
- 无权限入口直接不渲染；后端仍必须校验。

## 4. 界面纪律

- 一套系统字族；四档字号 22 / 14 / 13 / 12；无衬线标题。
- 无渐变、无入场动画、无 hover 位移、无辉光；分隔只用 1px 线。
- 空态一行 `<b>`；错误态一行 + 重试；不写“XX 会出现在这里”。
- 加文案先过三问：动作标签？数据？改不了的事实？都不是就删。
- 退役类名出现即红：`page-kicker` / `page-sub` / `card-kicker` / `card-sub` / `card-hint` / `ai-caveat` / `eyebrow` / `lede` / `av-*`。
- 守卫：`src/ui/__tests__/copyLaw.test.ts` + `visualLaw.test.ts`；规则全文见 `开发规范.md` §8.2。

## 5. 验证命令

```bash
cd frontend
npm run lint && npm run typecheck && npm run lint:api-refs
npm run test && npm run build && npm run size:gate
npm run format:check && npm run format:check:e2e
PW_PORT=5174 npx playwright test
PW_PORT=5175 npx playwright test -c playwright.visual.ts
```

- Vite 必须用 `localhost`，`127.0.0.1` 连不上。
- e2e 后端需 `RATELIMIT_LOGIN_LIMIT=200`；否则大面积 403/429。
- 视觉结论只有与基线 md5 相等且字节差 0 才能说“逐字节相同”。
