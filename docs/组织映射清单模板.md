# 组织映射清单模板（B-12 / P-08 开工前置）

> **用途**：B-12/P-08 开工前，把现存自由文本（学院/专业/行政班/学期/课程归属）映射到目标实体 ID，作为 V12–V15 回填的唯一输入。
>
> **依据**：[后端信息架构改造交接.md](后端信息架构改造交接.md) §6.3 与 §9 决策 9A：
> **不自动推断；每门课程建一个默认教学班；无法映射的记录必须迁移失败并输出清单，不得用默认值静默填充。**
>
> **本模板状态**：⏳ 空表，**尚未完成任何映射**。填写后须项目主签字，签字前 V12–V16 不得启动。
>
> **存放约定**：填写版不要提交真实学生/教师姓名等个人信息；如需入库，只提交编码与 ID，源值脱敏后放 `deploy/mappings/`（该目录默认不入库），或按项目主指定路径单独保管。

---

## 1. 填写规则

1. **一行一个源值**：源值必须来自生产库的实际取值，不得写示例；同一源值出现多次时先做去重统计。
2. **目标 ID 必须真实存在**：填写前先在目标表插好学院/专业/行政班/学期，再回填 ID；不得先填 ID 后建行。
3. **不允许留空**：无法映射的行必须移入 §7「未映射清单」，并写明原因与处理人；`目标 ID` 列留空即视为未映射。
4. **课程归属不是按教师猜**：`courses.college_id` 需按课程所属学院确认，不得用 `courses.teacher_id` 的部门自动推断。
5. **学期**：库内只存规范学期名（如 `2026-2027-1`）；展示别名（如「2026 秋」）另列，仅用于界面（10A）。
6. **课程编号**：V16 前保留全局唯一；若存在跨学期同编号，先在 §6 列出并确认处理方式（4A）。
