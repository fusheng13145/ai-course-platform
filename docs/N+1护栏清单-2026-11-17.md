## 3. 未建：全量 SQL 计数门禁

要做「每个端点请求的 SQL 条数 ≤ 固定阈值」，需要：

1. `@SpringBootTest` + H2/Testcontainers 真库（现有 `ServiceTestBase` 把 Mapper 全部 mock，量不到 SQL）；
2. 一个测试专用 MyBatis `Interceptor` 统计 `Executor.query/update` 次数，按线程绑定；
3. 端点 → 阈值清单（含分页、报表、导出、AI 会话等），阈值要按实测基线定，不能拍脑袋；
4. CI 串行跑，避免跨测试污染计数。

本批不做，原因：会引入新的测试基础设施与阈值口径，超出「关键接口护栏」范围；已在 `docs/后端待办项.md` B-03 备注为后续项，不宣称「全量门禁已建成」。

## 4. 维护规则

- 新增「列表 + 逐行补字段」的服务方法，必须同时补一条 `verify(...times(1))` 或 `never()` 断言，否则视为未完成。
- 断言钉**调用次数与批量方法名**，不钉 SQL 文本、不钉表名（表名会随迁移变化）。
- 允许「循环内调 Service」但该 Service 内部必须批量；不能因为「看起来只查一次」就跳过断言。
