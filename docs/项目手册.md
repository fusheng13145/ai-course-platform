## 1. 项目概览

**一句话**：面向高校课程教学的 AI 课程平台，以“课程—章节—任务/试卷—提交/作答—批阅—学情”为主干，叠加知识图谱、RAG 问答、AI 出题/批改/学习建议与 LoRA 微调，服务学生、教师、管理员三类角色。

### 1.1 阶段与边界

| 项 | 事实 |
| --- | --- |
| Phase 1 | **单租户生产系统**，按 ≥10,000 注册用户设计容量；QPS/SLA 以目标环境压测为准，不提前承诺 |
| Phase 2 | 多租户 SaaS 为后续扩展；Phase 1 只保留 `tenant_id` 等扩展点，**不声称已支持多租户** |
| 部署姿态 | 本机原生进程是开发/验收姿态，不是生产交付；生产必须具备 TLS/反代、编排、密钥、备份恢复、监控告警、回滚能力 |
| 演示数据 | V5–V7、V12_1 只进开发/验收环境；生产空库开通并排除演示号段。当前开发库已执行 V18 清理与后续真实课程数据补齐 |
| 样例课程 | 《计算机网络》`4178`（`CN202`）；课程 1–6 保留开发演示数据 |

### 1.2 系统组成

| 层 | 组成 | 说明 |
| --- | --- | --- |
| 前端 | Vue 3 + Vite + Pinia + Vue Router，无第三方组件库 | 单页应用，`/api` 代理到后端；`src/ui/**` 已接管根路径 |
| 后端 | Spring Boot 3.5 + Java 21 + MyBatis-Plus | 业务、鉴权、事务、审计、调度 |
| 数据 | MySQL 8.4 + Redis 7.4 | 业务数据、缓存、限流、会话 |
| AI 引擎 | Python FastAPI：KG 8001 / RAG 8002 / LoRA 8003 | 独立进程，经 `integration/` 契约层调用 |
| 图谱库 | Neo4j 5.26 | KG 持久化；不可达时回落内存图 |
| 可观测 | Actuator + Prometheus/Grafana/Loki/Alertmanager | 配置齐备；目标环境未实跑，不能宣称已具备生产可观测性 |

### 1.3 当前能力

- **教学主链**：建课 → 章节 → 任务/试卷 → 发布 → 提交 → 批阅/退回 → 成绩与学情，已闭环。
- **AI 主链**：问答、出题、批改、学习建议；失败统一 503 降级，不伪造成功。
- **知识图谱**：课程级知识点与关系、力导向图、最短路径、AI 抽取；KG 不可达时本地 BFS 兜底。
- **学生学业档案**：成绩单、学情报告、学习路径、薄弱点分析；成绩单为打印版，电子印章未实现。
- **AI 助教**：AI 问答、AI 语料、AI 出题/批改/学习建议统一归入 AI 助教入口；在线监考归入考试页。

## 2. 角色与权限

| 角色 | 代码 | 核心诉求 | 默认落点 |
| --- | --- | --- | --- |
| 学生 | `STUDENT` | 学课程、做任务/考试、看成绩与反馈、问 AI | `/student` |
| 教师 | `TEACHER` | 建课与内容、组卷与批阅、看学情、管知识库 | `/teacher` |
| 管理员 | `ADMIN` | 用户/班级/权限、课程治理、内容审核、系统日志与 AI 用量 | `/admin` |

规则：

- **方法级**：Controller 的 `@PreAuthorize` 是主闸门；类级注解只作兜底。
- **对象级**：课程、资源、提交、成绩等必须校验“当前用户是否拥有该对象”，不能只校验已登录。
- **前端**：权限只决定入口可见性，不承担安全职责；所有隐藏都必须有后端对应校验。
- **角色变更**：JWT 只作快照，后端每次请求读取现行角色，改角色即时生效。
- **管理端导航**：7 个治理分区、23 条路径、13 个图标。

演示账号由 `DEMO_ACCOUNTS_ENABLED` 控制；生产必须 `false`，并提供 `APP_ADMIN_INITIAL_PASSWORD`，否则启动 fail-fast。文档只保留演示种子口径，不把开发库口令当作生产能力。

## 6. 协作与贡献

- **分支**：`feature/<描述>` / `fix/<描述>`；PR base `main`；squash merge；合并后删 head。
- **日常**：只本地 `git commit`，不推送；推送与 PR 仅在里程碑，PR 由项目主提交。
- **验证**：改什么跑什么；后端 `mvn -B -o clean verify -DskipITs`，前端 `npm run lint && npm run typecheck && npm run test && npm run build`，脚本 `python -m pytest scripts/tests -q`。
- **证据**：每个结论至少一条可重放命令；数字带时点、口径与命令；负向断言配阴性对照。
- **密钥**：永不回显值；只进 `.env` / `deploy/secrets/`；凭据贴进对话即视为外泄，唯一止血是轮换。
- **Windows**：`.bat` 纯 ASCII + CRLF；PowerShell 下 `-Dkey=value` 前加 `--%`；Vite 必须用 `localhost`。
- **禁止**：`git rm` / `git mv` / `git restore --worktree`；`sed` / `echo >` 改文件；并发覆盖率构建；批次外顺手清理。

## 7. 审计台账（摘要）

完整 DR-1…DR-111 记录保留在 Git 历史与旧版手册中；当前只保留会继续影响实现的结论：

| 主题 | 结论 |
| --- | --- |
| 对象级 ACL | 资源、提交、成绩、讨论、AI 会话、RAG 文档均按课程/归属校验；前端隐藏不等于后端放行 |
| AI 失败语义 | LLM 失败必须 503；删除“失败仍 200 + 兜底文案”旧行为 |
| 密钥 | 形状门、ASCII 门、历史复用检测、轮换记录；不得打印值 |
| 启动器 | 单入口 `start-all.py`；接管不重启；子树收尸；IPv6 回环探测；凭证 fail-fast |
| 存储 | 上传根从仓库 `uploads/` 迁到 `data/aicourse-platform/storage` + MinIO；旧路径只读兼容 |
| 前端 | 旧端已删除；`src/ui/**` 接管根路径；无第三方组件库；视觉基线 5 锚点 × 明暗 |
| 数据库 | 迁移只前向；已应用校验和冻结；`index.sql` 与迁移链需一致 |
| 文档 | 唯一索引 `docs/README.md`；数字只写一处；历史证据不静默删除 |
