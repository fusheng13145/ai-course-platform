# AI智能课程平台 — 需求规格说明书

## 1. 项目概述

### 1.1 项目背景
AI智能课程平台是一套基于人工智能技术的在线学习管理系统（LMS），面向高校和培训机构，提供课程管理、在线考试、知识图谱、AI辅助学习等全流程功能。平台采用B/S架构，支持多角色（管理员、教师、学生）协同工作。

### 1.2 技术栈
- **后端**: Spring Boot 3.5.15 + Java 25
- **ORM**: MyBatis-Plus 3.5.7
- **数据库**: MySQL 8.0 + Redis 7.x（可选）
- **安全**: Spring Security + JWT（jjwt 0.12.3）
- **前端**: Vue 3.5 + Vite 8 + Element Plus 2.4 + Pinia + Vue Router 4
- **可视化**: ECharts 5 + vue-echarts 6
- **AI**: DeepSeek API 集成
- **实时通信**: WebSocket

### 1.3 系统架构
```
┌─────────────────────────────────────────────────┐
│  Frontend (Vue 3 + Element Plus)               │
│  localhost:5173 → proxy → /api → localhost:8080 │
│  WebSocket: ws://localhost:8080/ws/notifications │
├─────────────────────────────────────────────────┤
│  Backend (Spring Boot)                          │
│  Controller → Service → Mapper → DB             │
│  Security (JWT Filter) → Auth → RBAC            │
│  WebSocket Handler                              │
├─────────────────────────────────────────────────┤
│  MySQL 8.0 (32 tables) + Redis (Session/Cache)  │
└─────────────────────────────────────────────────┘
```

## 5. API 接口规范

### 公共前缀: `/api`
### 响应格式:
```json
{ "code": 200, "message": "成功", "data": {} }
{ "code": 200, "message": "成功", "data": { "list": [], "total": 0, "page": 1, "pageSize": 10 } }
```

### 关键接口列表:
- `POST /auth/login` — 登录
- `POST /auth/register` — 注册
- `GET /auth/me` — 当前用户
- `POST /auth/logout` — 安全退出
- `POST /auth/change-password` — 修改密码
- `GET /auth/permissions` — 获取权限
- `CRUD /users` — 用户管理
- `CRUD /courses` — 课程管理
- `POST /courses/{id}/approve|reject` — 课程审核
- `CRUD /courses/{id}/chapters` — 章节管理
- `POST /enrollments` — 选课
- `CRUD /exam-papers` — 试卷管理
- `POST /exam-papers/{id}/start` — 开始考试
- `POST /exam-sessions/{id}/submit` — 提交答卷
- `GET /knowledge-points/graph/{id}` — 知识图谱
- `POST /ai/chat` — AI对话
- `GET /analytics/dashboard` — 仪表盘统计

### WebSocket端点:
- `/ws/notifications` — 实时通知推送

## 7. 部署说明

### 开发环境启动
```bash
# 后端（含热部署）
cd backend && ./mvnw.cmd spring-boot:run

# 前端（需先启动后端）
cd frontend && npm run dev
```

### 环境变量配置（生产环境必需）
| 变量名 | 说明 |
|--------|------|
| JWT_SECRET | JWT签名密钥 |
| MAIL_USERNAME | 邮箱账号 |
| MAIL_PASSWORD | 邮箱授权码 |
| DEEPSEEK_API_KEY | DeepSeek API密钥（可选） |

### 技术组件运行条件
- MySQL 8.0（数据库：ai_course_platform）
- Redis（缓存/会话，可选）
- JDK 17+（推荐25）
- Node.js 18+

## 9. 安全规范

### 环境变量敏感配置
- JWT_SECRET: 必须配置环境变量，禁止硬编码
- MAIL_USERNAME/MAIL_PASSWORD: 必须配置环境变量
- DEEPSEEK_API_KEY: 生产环境必须配置

### 权限控制
- 所有写操作端点必须添加 @PreAuthorize 注解
- 使用 Spring Security RBAC 角色权限控制
- JWT Token 过期时间配置合理

## 10. 代码质量规范

### 后端规范
- 严格采用三层架构（Controller → Service → Mapper）
- 使用 Lombok 简化代码
- 统一异常处理（GlobalExceptionHandler）
- 参数校验使用 @Validated 注解

### 前端规范
- 使用 Pinia 进行状态管理
- 统一 API 请求封装（request.js）
- 路由守卫进行权限控制
- Element Plus 按需自动导入
