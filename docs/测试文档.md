## 3. 后端

### 3.1 常用命令

```bash
cd backend
mvn -B -o clean verify -DskipITs        # 单元口径 + JaCoCo + SpotBugs + ArchUnit
mvn -B -o clean verify                 # 含集成层，需 Docker；本机当前不跑
mvn --% -Dtest=RagEngineModeTest -Djacoco.skip=true test   # PowerShell 单类
```

### 3.2 口径

- 同时读 **failures 与 errors**；`Failures: 0` 但套件不绿，常见是上下文加载失败记成 Errors。
- 覆盖率 0% 或异常低，先查并发构建互截 `jacoco.exec`，再查非 clean；必须**串行 + clean**。
- 中文路径下 JaCoCo 不生成 exec：加 `-Djacoco.skip=true` 或换短英文路径。
- 本机常规只跑 `-DskipITs`；16 例 Docker/真实库 IT 的权威读数在 CI，不得拼接引用。
- 例外：`AuthFlowIntegrationTest` 5 例不依赖 Docker，2026-11-19 在本机 `ai_course_platform_test` 独立库重建后通过；这 5 例不得被扩写成“容器化集成层已验证”。

## 4. 前端

### 4.1 常用命令

```bash
cd frontend
npm run lint && npm run typecheck && npm run lint:api-refs
npm run test && npm run build && npm run size:gate
npm run format:check && npm run format:check:e2e
PW_PORT=5174 npx playwright test
PW_PORT=5175 npx playwright test -c playwright.visual.ts
```

### 4.2 硬前置

- Vite 只绑 `[::1]`：必须用 `http://localhost:5173`，`127.0.0.1` 连不上。
- e2e 后端按 `RATELIMIT_LOGIN_LIMIT=200` 启动，否则大面积 403/429；报错文本会点名该变量。
- e2e 夹具过期会整批跳 `/login`：按配方重生成 `.auth`，不改断言。
- 5176+ 不在 CORS 白名单，登录会被拒；e2e 用 5174，视觉用 5175。
- 流程 e2e 与视觉不要并发跑同一后端；会互相污染会话与数据。

### 4.3 视觉

- 基线只覆盖 5 个锚点页、明暗各一，共 10 张；**不能宣称全站无视觉回归**。
- `threshold:0` 仍会跳过抗锯齿像素；只有与基线 **md5 相等且字节差 0** 才能说“逐字节相同”。
- 引用读数必须带截图尺寸与当次命令。

## 8. 证据纪律

1. 每个结论至少一条可重放命令；只有截图没有命令不算交付证据。
2. 数字带时点 + 口径；后端“单元口径”和“含 IT”不可拼接。
3. RED → GREEN 成对留痕：先留失败断言原文，再留通过读数。
4. 负向断言必须配阴性对照：先证明检测器能抓住人造违规样例。
5. 断言钉语义、钉结构，不钉会迁移的活文件路径与行号。
6. `ast.unparse` 会把双引号规范成单引号；按源码文本匹配前先归一化。
