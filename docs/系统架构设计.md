## 1. 总览

```text
浏览器（学生/教师/管理员）
  │ HTTPS /api、/api/ws
  ▼
Spring Boot 3.5 单体（8080，/api）
  │ JDBC/MySQL      │ Redis        │ MinIO/Storage      │ HTTP 契约
  ▼                 ▼              ▼                    ▼
MySQL 8.4         Redis 7.4      MinIO 9000        Python Engine Hub 8600
  业务/迁移/审计    缓存/限流/会话   bucket 上传对象    KG / DeepGraph+知识库 / 微调 单进程
                                                         │
                                                         ▼
                                                    Neo4j 5.26（KG 持久化）
```

- **形态**：模块化单体 + 一个 Python Engine Hub（8600）进程；`ENGINE_LAYOUT=separate` 可回退为 8001/8501/8003 三进程布局。不引入消息队列、不拆微服务。
- **前端**：Vue 3 SPA，`src/ui/**` 接管根路径，无第三方组件库。
- **部署**：开发/验收为本机原生进程；生产目标为反代/TLS + 编排，尚未在目标环境实跑。

## 4. 后端模块

| 模块 | 职责 | 关键约束 |
| --- | --- | --- |
| `auth` | 登录、刷新、登出、密码、会话、权限下发 | JWT 快照 + DB 现行角色；方法级 `@PreAuthorize` |
| `course` | 课程库、开课任务、教学班、章节、选课/退课、成员 | 三层课程模型；对象级 ACL |
| `task` | 作业发布、提交、附件、退回、截止/延期 | 提交归属与课程成员校验 |
| `exam` | 试卷、题目、考试会话、作答、自动保存、交卷、监考 | 会话状态机；超时/强制交卷幂等 |
| `grade` | 成绩方案、成绩项、总评、分布、学情 | 总评计算单一入口；快照可追溯 |
| `kg` | 知识点、关系、图查询、路径、抽取、同步 | 图数据库不可达时 BFS 兜底并标注 |
| `ai` | 问答、出题、批改、学习建议、会话 | 统一 503；不伪造生成结果 |
| `storage` | 上传、分片、MinIO、`/uploads` 代理 | `StorageLayout` 唯一路径口径；防穿越 |
| `notification` | 站内信、铃铛、WebSocket、课程通知 | 未读计数与推送分离 |
| `admin` | 用户/班级/权限、审核、日志、AI 用量 | 管理端角色 + 学院范围 |
| `common` | 响应、异常、审计、工具、契约常量 | 统一错误码与 `ContractPaths` |

### 4.1 请求链

```text
HTTP → CORS/CSRF → JWT 解析 → 角色/权限 → Controller
     → Service（事务/缓存/ACL）→ Mapper → MySQL/Redis/MinIO
     → 统一响应/异常 → 审计/日志
```

- Controller 只做参数校验、权限与编排，不写业务规则。
- Service 是事务边界；跨表写操作必须 `@Transactional(rollbackFor = Exception.class)`。
- Mapper 不写业务分支；复杂查询用 XML，动态 SQL 必须可解释。
- 外部引擎调用统一走 `integration/` 契约层，不散落 HTTP 客户端。

### 5.2 Redis

- 缓存：用户资料、权限、课程列表等；键必须带业务前缀与 TTL。
- 限流：登录、AI、上传；Lua 原子化；不可用即故障。
- 会话：刷新令牌/强制下线；与 JWT 失效策略一致。

### 5.3 对象存储

- 运行期根：`data/aicourse-platform/`；`storage/` + `minio-data/`。
- MinIO bucket：`aicourse-uploads`；`/uploads/**` 由后端代理读取。
- 路径口径唯一由 `StorageLayout` 承担；禁止在业务代码拼 `uploads/`。

## 6. API 契约

| 项 | 规则 |
| --- | --- |
| 前缀 | `/api`；版本化端点按现有路径，不随意改 |
| 响应 | 统一 `code/message/data`；分页含 `total/page/size` |
| 错误 | 业务错误 4xx；依赖不可用 **503**；不把失败包装成 200 |
| 契约常量 | `ContractPaths` 是 Java/Python 共享路径与降级判定唯一来源 |
| SSE | 问答流式；断线可重连；结束帧明确 |
| 时间 | ISO-8601；服务端时区 Asia/Shanghai |
| ID | 数值型业务 ID；不对外暴露内部自增细节 |
| 权限 | 每个写端点必须方法级 + 对象级校验 |

### 6.1 Java ↔ Python

| 方向 | 契约 |
| --- | --- |
| Java → RAG | `/retrieve`、`/ask`；503 表示不可用，Java 不重试直接降级 |
| Java → KG | 图查询、抽取、路径；失败标注 `degraded`，不伪造图结果 |
| Java → FT | 数据集、训练、权重；长任务异步 + 状态查询 |
| Python → Java | 不反向调用业务；只读契约所需配置 |

**双引擎真实含义**：Python 知识库 RAG（8501，原 8002 已并入）↔ 纯 LLM（无检索）。Java 侧没有 BM25 实现；`RAG_PROVIDER=java` 只是不调 Python，直接纯 LLM。

## 7. 安全

| 面 | 规则 |
| --- | --- |
| 认证 | JWT + 刷新令牌；登出/强制下线使会话失效 |
| 授权 | 方法级 `@PreAuthorize` + 对象级 ACL；管理端按学院范围 |
| 上传 | 类型/大小/分片校验；路径穿越防护；资源行回查 ACL |
| CSRF/CORS | 生产开启 CSRF；CORS 只允许白名单源；Vite 用 `localhost` |
| 限流 | 登录按 IP+账号；AI/上传按用户；429 打日志 |
| 密钥 | `.env` / `deploy/secrets`；永不回显；轮换记录 |
| 审计 | 登录、管理操作、AI 调用、敏感读写留痕 |

## 8. 前端

- **路由**：外层学生 4 入口、教师 3 入口；课程能力全部挂课程。
- **UI 层**：`src/ui/**` 自有令牌与组件；无第三方组件库。
- **状态**：Pinia 按域拆分；请求层统一错误/401/503 处理。
- **视觉**：5 锚点 × 明暗 10 张基线；无渐变/入场动画/hover 位移。
- **无障碍**：焦点管理、键盘可达、reduced-motion；不是 WCAG 合规声明。

## 11. 关键决策

| 决策 | 理由 |
| --- | --- |
| 模块化单体 | 单团队、单课程优先；拆微服务增加契约与运维成本 |
| 不引入 MQ | 当前吞吐与异步需求可由调度 + 线程池 + Redis 承担；上线前再评估 |
| Phase 1 不做多租户 | 先做深单租户；保留 `tenant_id` 扩展点 |
| Python 引擎独立 | RAG/KG/FT 依赖重、迭代快；HTTP 契约隔离 |
| MinIO 对象存储 | 避免仓库内上传目录膨胀；统一 `/uploads` 代理 |
| 统一 503 降级 | 失败不伪装成功；前端可识别 |
| 图谱不可用 BFS 兜底 | 保证教学主链可用；响应标注降级 |
