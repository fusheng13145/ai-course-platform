> **文档定位**：把 [后端信息架构改造交接.md](后端信息架构改造交接.md) §1–§8 的目标契约，按 §9 已定的 1A–10A 口径拆成可排期、可验收的工作包。本文**只做拆包与排期**，不改变任何代码、不建迁移、不开工。
>
> **决策依据**：2026-11-05 项目主已确认交接文档 §9 的 10 项决策，全部采用「建议默认」（1A–10A）；本文不再讨论选型，只落地顺序与判据。
>
> **估算性质**：人日为**按 §7 清单称重后的估算**，不是承诺工期；与 [后端待办项.md](后端待办项.md) §11.1 P-08 的 **36–54 人日**同口径，逐包相加可复算（见 §4）。
>
> **本轮状态**：⏳ **未开工**。V12–V16 迁移号已由 P-08 预留（[后端待办项.md](后端待办项.md) §11.4），未排期前不取用、不写迁移文件。

## 0. 一页结论

- **10 个工作包**（WP1–WP10）+ 1 个强制前置（映射清单签字），依赖为**串行为主、WP5 之后可两线并行**。
- **关键路径**：WP1（V12 组织底座）→ WP4（V13 教学班）→ WP5（名单）→ WP7（快照）→ WP10（V16 收口）。
- **人日**：**36–54**，与既有 P-08 口径一致；单包最大 5–7 人日，适合 1 人或 2 人并行，不适合与 P-06 S-01 同批。
- **发布窗口**：V12–V15 可随迭代发布（expand），**V16 必须单独发布窗口**（contract），且 V16 后至少一个发布周期才做清理迁移。
- **三条硬约束**：不改 V1；无法映射的旧自由文本**迁移失败并输出清单**（9A），不得静默填默认值；管理员只读治理、不代批阅/不改成绩。
- **前端不在本包**：§7.3 的 API 联调面另计；后端未落地前，学院/教学班/审批/名单四页继续显示「后端尚未提供」。

## 3. 工作包清单

> 每包给出：目标、前置、范围、交付物、验收标准、人日。验收标准以**可执行断言**为主，不写「体验良好」类表述。

### WP1 组织与作用域底座（V12）

- **目标**：建 `schools`/`colleges`/`majors`/`admin_classes`；`users` 加 org 列与 `admin_scope`；`role_permissions` 唯一键改 `(role, scope, permission_key)`；插单校根。
- **前置**：P0-1…P0-5。
- **范围**：Entity/Mapper（School、College、Major、AdminClass）+ `OrgService` + `OrgController`/`AdminOrgController` 基础读写；`AdminScope` 常量。
- **不做**：旧自由文本自动映射；删 `classrooms`/`users.class_id`。
- **交付物**：`V12__org_foundation.sql`；四实体四 Mapper；组织树查询端点；`index.sql` 同步；schema 守卫通过。
- **验收**：
  1. 空库迁移后 `schools` 恰 1 行；`ADMIN` 账号 `admin_scope=SCHOOL`。
  2. 旧 `classrooms`/`users.class_id` 仍存在且旧代码可跑（既有测试全绿）。
  3. `IndexSqlMigrationGuardTest`、`ContractTestSchemaBootstrapTest` 全绿。
  4. 组织树端点对未登录返回 401、非管理员返回 403。
- **人日**：**4–7**

### WP2 管理员作用域与权限目录

- **目标**：JWT 过滤器附加 `SCOPE_ADMIN_SCHOOL`/`SCOPE_ADMIN_COLLEGE`；`/admin/**` 校级端点收紧；`role_permissions` 按 scope 读写。
- **前置**：WP1。
- **范围**：`JwtRequestFilter`、`SecurityConfig`、`PermissionController`/`RolePermission`、种子（校级 + 院系级演示管理员，后者只进 `db/seed-demo`）。
- **验收**：
  1. 校级管理员可写学期/角色/系统设置；院系管理员同端点 403。
  2. 院系管理员访问他院用户/课程返回 403（允许 + 拒绝各一条测试）。
  3. 既有 `ROLE_*` authority 不变，旧登录链路测试全绿。
  4. 权限目录唯一键冲突用例（同 role 同 key 不同 scope）通过。
- **人日**：**4–6**

### WP3 课程审批与审批流水（V13 一部分）

- **目标**：`course_approval_records`；审批服务写 `approved_by` 与流水；课程列表支持 approval/college 过滤；驳回后可重提。
- **前置**：WP1、WP2。
- **范围**：`CourseApprovalRecord` + `CourseApprovalService`；`CourseServiceImpl`/`CourseController` 创建与审批路径；缓存逐出。
- **验收**：
  1. 课程负责人创建 → `PENDING`；不能指定他人 owner。
  2. 院系管理员审批本院课程成功并落 `approved_by`/流水；他院课程 403。
  3. `REJECTED → PENDING` 重提后历史流水保留。
  4. 审批队列只返回作用域内课程（校级全部、院系本院）。
- **人日**：**4–6**

### WP4 教学班与主讲归属（V13 主体）

- **目标**：`teaching_classes`、`teaching_class_admin_classes`；存量课程建默认教学班（9A）；主讲指派限本院教师（2A）；教学班 ACL。
- **前置**：WP1、WP3；P0-1 签字。
- **范围**：`TeachingClass`/`TeachingClassAdminClass` + `TeachingClassService` + `TeachingClassController`；`TeachingClassAccessControl`。
- **回填**：`lead_teacher_id = courses.teacher_id`；名称 `concat(name,' 默认教学班')`；`APPROVED→ACTIVE`，否则 `DRAFT`。
- **验收**：
  1. 每门存量课程恰 1 个默认教学班；无孤儿 `course_id`/`lead_teacher_id`。
  2. 只有课程负责人可建教学班；课程未通过时为 `DRAFT`。
  3. 指派他院教师 403；指派本院教师成功。
  4. 同课程其他教学班主讲访问本班名单/成绩 403。
- **人日**：**4–6**

### WP5 选课名单与教学班成员

- **目标**：`course_enrollments` 加 `teaching_class_id/source/source_admin_class_id`；名单导入与重同步；自助选课容量/审批按教学班；学生课程列表过滤 `APPROVED`。
- **前置**：WP4。
- **范围**：`CourseEnrollment` 扩展 + `RosterService` + 现有 `CourseEnrollmentController`/`ServiceImpl` 改造；`source` 枚举。
- **验收**：
  1. 存量选课全部回填到默认教学班，`source=LEGACY`，空值数 0。
  2. 行政班导入生成 `ADMIN_CLASS_IMPORT`；重复/冲突不静默覆盖。
  3. 重同步返回 `added/removed/skipped`，不删手工/自助记录。
  4. 学生「我的课程」只含 `APPROVED`，每条带教学班；选满/选错班返回明确 400/409。
- **人日**：**4–6**

### WP6 任务/试卷教学目标（V14 一部分）

- **目标**：`task_teaching_classes`/`exam_teaching_classes`；`tasks`/`exam_papers` 加 `visibility`；默认 `COURSE`（5A）；列表与表单按 `teachingClassId` 过滤。
- **前置**：WP4、WP5。
- **范围**：两张目标表 + `Task`/`ExamPaper` 目标写入；教师端列表过滤。
- **验收**：
  1. 存量任务/试卷统一 `visibility=COURSE`，**不批量插目标行**；新建教学班自动继承。
  2. `visibility=CLASSES` 的记录至少一个目标行（约束/服务断言）。
  3. 同课程非目标教学班教师看不到该活动，目标班可见。
  4. 管理员调用发布/改目标 403。
- **人日**：**3–4**

### WP7 提交/考试/成绩快照

- **目标**：`submissions`/`task_completions`/`exam_sessions`/`grade_items` 加 `teaching_class_id` 快照并按成员关系回填；讨论加可空 `teaching_class_id`。
- **前置**：WP5、WP6。
- **范围**：四实体快照写入；统计/成绩按教学班过滤；`discussion_topics` 可空列（存量保持 `NULL`）。
- **验收**：
  1. 存量四类记录快照空值数 0（按学生当前课程成员回填）。
  2. 新提交/考试/成绩写入时从成员关系取快照，不从请求体信任。
  3. 学生转班后历史记录仍归属原教学班（不随成员关系漂移）。
  4. 成绩统计按教学班口径与旧课程级口径差异可解释（同数据两口径留读数）。
- **人日**：**3–4**

### WP8 公告与通知扇出（V15）

- **目标**：`announcements` + 7A 扇出到 `notifications` 并记已读；教师课程公告、班主任班级公告入口；旧站内信继续可读。
- **前置**：WP5（受众需要教学班/行政班名单）。
- **范围**：`Announcement`/`AnnouncementService`/`AnnouncementController`；`NotificationService` 扇出；保留用户收件箱。
- **不做**：把历史 `notifications` 伪造成公告。
- **验收**：
  1. 公告按受众扇出条数 = 受众去重人数；`/notifications` 可见并可标已读。
  2. 非受众用户看不到该公告（列表与详情均 403/404）。
  3. 历史通知不迁移、仍可读。
  4. 班主任只能发本人行政班；教师只能发本人课程/教学班。
- **人日**：**3–4**

### WP9 班主任画像与管理端治理边界

- **目标**：`advisor_teacher_id` 改为当前登录教师自查；6A 只出聚合画像；8A 院系管理员审计/会话先 403；管理员写教学数据 403、读数据 200。
- **前置**：WP2、WP5、WP8。
- **范围**：`AdvisorService`/`AdvisorController`、`ClassroomController` 旧端点收紧、`AnalyticsService` 增加 `adminClass`/`teachingClass` 分组、管理员只读矩阵。
- **验收**：
  1. `getMyClassrooms` 无 `advisorId` 入参，只返回当前教师班；查他人班 403。
  2. 班主任画像只含聚合值，不含学生个人成绩字段（响应体断言）。
  3. 院系管理员访问审计/会话 403；校级管理员 200。
  4. 管理员调用批阅/改成绩/发布作业 403，读课程详情 200（逐端点矩阵）。
- **人日**：**2–4**

### WP10 V16 收口、学期命名与守卫同步

- **目标**：10A 学期别名 VO；4A 学期内唯一课程编号；V16 收紧 `NOT NULL` 与唯一键；`index.sql`、三个守卫、种子同步；V11→V16 集成测试。
- **前置**：WP1–WP9 全部完成且回填计数为 0 空值。
- **范围**：`V16__org_cutover.sql`；`semesters` 展示别名字段/VO；`OrgMigrationBackfillTest`；清理迁移另立版本（不早于 V16 一个发布周期）。
- **验收**：
  1. 回填校验 8 条全部为 0：学生 `admin_class_id`、课程 `semester_id`/`college_id`、成员 `teaching_class_id`、快照、`CLASSES` 目标行、无重复成员、无孤儿。
  2. 旧数据量前后一致：课程/学生/选课/任务/试卷/成绩记录数不减少。
  3. `(semester_id, code)` 唯一生效，旧 `uk_courses_code` 移除前已确认无跨学期重复。
  4. `index.sql` 独立建库成功；三个 schema 守卫全绿；至少一条 V11 快照 → V16 迁移集成测试。
  5. 学期接口返回规范名 + 展示别名，别名不写进课程表。
- **人日**：**5–7**

## 7. 全局验收标准（每包之外的整体判据）

1. **数据不丢**：迁移前后课程/学生/选课/任务/试卷/成绩记录数一致；旧 `classrooms` 行全部有对应行政班。
2. **权限双向**：§8.1 的 20 个场景每条都有「允许 200/成功」与「拒绝 403」断言，不做单边测试。
3. **管理员边界**：管理员写教学数据 403、读数据 200，逐端点矩阵入库。
4. **学生口径**：只看 `APPROVED` 课程，且每条带教学班。
5. **迁移可重跑**：回填脚本幂等，二次执行计数不变；失败输出清单而非默认值填充。
6. **测试门禁**：`mvn test` 全绿（当前基线 3143 例/0 失败）；新增迁移同步 `index.sql` 与三个守卫，否则不接受合并。
7. **不宣称**：后端落地前，学院/教学班/审批/名单页继续写「后端尚未提供」，不做假数据。
