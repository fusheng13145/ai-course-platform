# 脱敏三面核查（2026-11-07 · B-06 收口批）

> 口径：对"日志 / 回显 / 导出"三个泄露面逐点核查。判定标准：密码类凭证任何面都不得出现；
> 个人联系方式（邮箱/手机号）在非本人、非管理运营场景必须掩码；日志面不得携带原文敏感值。

## 一、核查结论总表

### 回显面

| 场景 | 核查结果 | 处置 |
| --- | --- | --- |
| 密码出参 | `User.password` 标 `@JsonIgnore`（实体层）+ 控制器显式 `setPassword(null)` 双保险；`failedLoginAttempts/lockedUntil/registerIp` 同样 `@JsonIgnore` | ✅ 已达标 |
| `GET /users/{id}` 非本人 | **缺口**：注释声明"非本人时脱敏邮箱和手机号"但未执行，管理员经此端点看原文、经 `/profile` 却是掩码（两处语义不一致） | ✅ **本次修复**：非本人路径 `assertUserAccess` 后套用同一 `maskSensitive`；新增正反 2 测试（本人原文 / 非本人掩码 `l***@example.com`、`138****5678`） |
| `GET /users/{id}/profile` 非本人 | `maskSensitive` 已生效 | ✅ 已达标 |
| `GET /users`（管理员列表） | 手机号/邮箱原文返回 | ✅ **保留（知情取舍）**：管理台运营需要完整联系方式检索/联系用户；本页仅 ADMIN 角色可达且受院系 scope 门禁。取舍记录于本文件与代码注释 |
| 系统配置非 ADMIN 读 | 键名含 `secret/password/token/credential/api_key/_key` → 值 `******`；非 ADMIN 仅见 `is_public` 项 | ✅ 已达标 |
| 题库/考试学生侧 | 学生脱敏答案（`GET /exam-papers/{id}/questions` 学生分支） | ✅ 已达标 |
| Excel 导入临时密码 | `POST /admin/users/import-excel` 响应返回系统生成的**一次性明文临时密码** | ✅ **保留（设计如此）**：仅本次响应出现一次、不落库原文；导入管理员本人操作。已在核查表登记为"受控例外" |

### 日志面

| 场景 | 核查结果 | 处置 |
| --- | --- | --- |
| 操作日志 params | `OperationLogAspect.maskSensitiveFields`：`password/oldPassword/newPassword/confirmPassword/code/authorization/accessToken/refreshToken/token/secret/apiKey/accessKey` 值替换 `***` | ✅ 已达标（P1-5 修复遗产） |
| 本次新增的审核 DELETE 留痕快照 | 落 `operation_logs`：内容摘要截 200 字符 + reason；**不含**密码类字段（讨论回复/资源文件名本就非凭证） | ✅ 新增点自审通过 |
| MyBatis SQL 日志 | 默认 `Slf4jImpl` 且受 INFO 级约束，生产默认不打印 SQL 参数 | ✅ 已达标（`SQL_LOG_IMPL` 仅排障临时开） |
| 登录日志 | 记录 IP/UA/归属地——属安全审计数据本身，非泄露面 | ✅ 合规 |
| AI 调用日志 | 记 provider/tokens/耗时/错误摘要，不含提问原文与答案 | ✅ 已达标 |

## 二、本次修复明细

1. **`UserController.getById` 对齐 `/profile` 语义**（见上表回显面第 2 行）：非本人路径先作用域门禁再 `maskSensitive`；javadoc 同步改写，消除"注释说做了、代码没做"的自欺点。
2. **新增测试 2 例**：`getById_otherUser_masksContactFields`（非本人掩码断言）、`getById_self_keepsContactFields`（本人原文不误伤）。

## 三、受控例外登记（不做脱敏的点及理由）

| 点 | 理由 | 防线 |
| --- | --- | --- |
| ADMIN 用户列表原文联系方式 | 管理运营刚需 | 角色门禁 + 院系 scope + 操作日志留痕 |
| 导入 Excel 一次性临时密码回显 | 无通知渠道时唯一交付方式 | 仅当次响应、强制首次登录改密策略 |
| 数据库备份原文 | 可恢复性刚需 | 备份卷/通道访问控制；异地同步落地后补传输加密 |

## 四、残余

- 通知多渠道（邮件）落地时，邮件正文如携带成绩等敏感内容需评估传输面——已在路线图 §C 标注前置条件。
- 导出审计（谁在何时导出了什么）当前仅覆盖走 AOP 的导出端点；xlsx 前端本地导出无服务端留痕，属可接受边界（数据本身已在页面内）。
