## 1. 项目概述

- **项目名称**：基于知识图谱 + LLM 的 AI 助教系统
- **项目来源**：江苏科技大学校级教育教学改革课题《生成式人工智能赋能网络类课程教学改革研究》
- **定位**：以《计算机网络》专业课程为试点，融合知识图谱与大语言模型（RAG），构建智能教学辅助系统，解决知识碎片化、个性化学习不足、大模型知识幻觉等痛点。
- **技术栈**：Spring Boot 3.x + MyBatis-Plus + Spring Security（后端）；Vue 3 + Vite + Element Plus + ECharts + Pinia（前端）；MySQL 8.0；Redis 7（缓存，可选）；DeepSeek API（AI）。
- **源码体量**：后端主代码 Java 源文件（**40 Controller** / 50 Service Impl / 47 Mapper / 47 Entity / 50 DTO）+ 10 个测试 Java 文件（含 103 个 `@Test` 方法）；前端 Vue3 源码 65 个页面 + 34 个 API 模块（含 request.js 请求封装）。
  - 较早期版本新增 AI 对话会话持久化相关 8 个文件：2 Entity（AiChatSession / AiChatMessage）+ 2 Mapper + 2 Service 接口/实现（AiChatSessionService / AiChatMessageService）。
  - 接口粒度说明：PRD 功能接口矩阵为 **93 个功能性接口**（公共 9 + 教师 28 + 学生 18 + 管理员 17 + AI 9 + 知识图谱 12）；代码层控制器端点**分布在 40 个控制器中**（经统一重构合并了知识图谱三控制器与课程教学控制器，端点总数以 springdoc 为准）。两者口径不同，功能基线 93 个均已达 100% 落地（详见 §3.1）。

## 2. 技术架构

```
应用层：    智能问答 / 知识可视化 / 学情分析 / 系统管理
RAG 引擎层： 查询理解 / 分层检索 / 语义召回 / 生成融合
知识存储层： MySQL 关系库 + (Neo4j 图库预留) + (Milvus 向量库预留)
基础服务层： DeepSeek API / 嵌入模型 / 缓存 / 消息队列
```

## 4. 部署指南

### 4.1 本地开发（Redis 可选）

```bash
# 后端
cd backend
./mvnw.cmd spring-boot:run
# 或打包运行
mvn clean package && java -jar target/ai-course-platform-0.0.1-SNAPSHOT.jar

# 前端
cd frontend
npm install && npm run dev
```

- 前端：http://localhost:5173 ｜ API：http://localhost:8080/api ｜ Swagger：http://localhost:8080/api/swagger-ui.html
- **Redis**：本地开发可选。不启动 Redis 时应用仍可运行（会话走数据库存储，仅部分缓存功能如验证码不生效）；启动 Redis 后自动启用缓存加速。
- 环境变量（根目录 `.env.example` 为模板）：`JWT_SECRET` / `DEEPSEEK_API_KEY` / `MAIL_USERNAME` / `MAIL_PASSWORD`，以及 Python 微服务地址 `KG_BASE_URL` / `RAG_BASE_URL` / `FT_BASE_URL`。
- **本地一键启动（已配置 DeepSeek 本地 Key）**：直接运行根目录 `start-backend.bat` 即可，脚本会自动激活 `local` 配置（`application-local.yaml`，其中含本地开发用 DeepSeek Key，已被 `.gitignore` 忽略），无需手动设置环境变量。生产环境请改用 `docker compose` 并注入 `DEEPSEEK_API_KEY`。

### 4.2 容器化部署（推荐，Redis 随容器启动）

```bash
docker compose up -d --build
```

`docker-compose.yml` 编排 MySQL + Redis + Backend + Frontend 四服务；在该模式下 Redis 随容器启动并启用缓存，**属于必要组件**。生产环境请在 `docker-compose.yml` 或 `.env` 中填充 `JWT_SECRET` / `DEEPSEEK_API_KEY` / `MAIL_*`。

> ⚠️ 早期交付文档中提到的 `docker build -t ai-course-platform .` + 单容器 `docker run -p 8080:8080 -p 5173:5173` 方式已废弃，请以本文件的 `docker-compose.yml` 为准。

| AI 调用异步化 | `Callable<ApiResponse>` + `AsyncMvcConfig` | 专用线程池（core4/max20/queue100/120s），长耗时 LLM 调用不阻塞 Tomcat 线程 |

| Redis 缓存学情聚合 | `AnalyticsServiceImpl` `@Cacheable` | `getDashboard`/`getTeacherDashboard`/`getPlatformOverview` 缓存 5min，评分 `gradeSubmission` 时 `@CacheEvict` |
| IP 级限流 | `RateLimitFilter` | 登录 60s/10 次、AI 60s/20 次，阈值由 `ratelimit.*` 配置 |
| 遗留接口收敛 | `AIController` 5 端点 `@Deprecated(forRemoval=true)` | 明确新旧边界（见 §3.1） |
| **验证** | 后端 `JAVA_HOME=JDK21 mvn clean compile` EXIT=0；前端 `npm run build -- --outDir .verify-dist` EXIT=0（仅 chunk 体积 / PURE 注解告警） | 三功能均已编译与构建验证 |
