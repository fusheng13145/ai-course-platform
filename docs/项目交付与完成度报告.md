## 1. 项目概述

- **项目名称**：基于知识图谱 + LLM 的 AI 助教系统
- **项目来源**：江苏科技大学校级教育教学改革课题《生成式人工智能赋能网络类课程教学改革研究》
- **定位**：以《计算机网络》专业课程为试点，融合知识图谱与大语言模型（RAG），构建智能教学辅助系统，解决知识碎片化、个性化学习不足、大模型知识幻觉等痛点。
- **技术栈**：Spring Boot 3.4.4 + MyBatis-Plus + Spring Security（后端）；Vue 3 + Vite + Element Plus + ECharts + Pinia（前端）；MySQL 8.0；Redis 7（**必选**：缓存/限流/AI 配额/验证码依赖，启动时强校验连通性）；DeepSeek API（AI）。
- **源码体量**：后端主代码 Java 源文件（**40 Controller** / 50 Service Impl / 47 Mapper / 47 Entity / 50 DTO）+ **80 个测试类（含 1303 个 `@Test` 方法）**；前端 Vue3 源码 **71 个视图页面 + 42 个 API 模块**（含 request.js 请求封装）。
  - 较早期版本新增 AI 对话会话持久化相关 8 个文件：2 Entity（AiChatSession / AiChatMessage）+ 2 Mapper + 2 Service 接口/实现（AiChatSessionService / AiChatMessageService）。
  - 接口粒度说明：PRD 功能接口矩阵为 **93 个功能性接口**（公共 9 + 教师 28 + 学生 18 + 管理员 17 + AI 9 + 知识图谱 12）；代码层控制器端点**分布在 40 个控制器中**（经统一重构合并了知识图谱三控制器与课程教学控制器，端点总数以 springdoc 为准）。两者口径不同，功能基线 93 个均已达 100% 落地（详见 §3.1）。

## 4. 部署指南

### 4.1 本地开发（Redis 必选）

```bash
# 后端
cd backend
./mvnw.cmd spring-boot:run
# 或打包运行
mvn clean package && java -jar target/ai-course-platform-0.0.1-SNAPSHOT.jar

# 前端
cd frontend
npm install && npm run dev
```

- 前端：http://localhost:5173 ｜ API：http://localhost:8080/api ｜ Swagger：http://localhost:8080/api/swagger-ui.html
- **Redis（必选）**：缓存/限流/AI 配额/验证码均依赖 Redis。应用启动时 `RedisStartupValidator` 会强校验连通性（fail-fast，不启动 Redis 则启动失败），`REDIS_REQUIRED=false` 仅用于单元测试场景关闭该校验。本地开发请先 `docker compose up -d redis`（或本地安装并启动 Redis）再启动后端。
- 环境变量（根目录 `.env.example` 为模板）：`JWT_SECRET` / `DEEPSEEK_API_KEY` / `MAIL_USERNAME` / `MAIL_PASSWORD` / `REDIS_PASSWORD`（可选，设置后 Redis 启用 requirepass 并向后端透传），以及安全开关 `COOKIE_SECURE` / `REQUIRE_HTTPS` / `CSRF_ENABLED`（默认 false，生产按需开启），Python 微服务地址 `KG_BASE_URL` / `RAG_BASE_URL` / `FT_BASE_URL`。
- **本地一键启动（已配置 DeepSeek 本地 Key）**：直接运行根目录 `start-backend.bat` 即可，脚本会自动激活 `local` 配置（`application-local.yaml`，其中含本地开发用 DeepSeek Key，已被 `.gitignore` 忽略），无需手动设置环境变量。生产环境请改用 `docker compose` 并注入 `DEEPSEEK_API_KEY`。

### 4.2 容器化部署（推荐，Redis 随容器启动）

```bash
docker compose up -d --build
```

`docker-compose.yml` 编排 MySQL + Redis + Backend + Frontend 四服务；在该模式下 Redis 随容器启动并启用缓存，**属于必要组件**。生产环境请在 `docker-compose.yml` 或 `.env` 中填充 `JWT_SECRET` / `DEEPSEEK_API_KEY` / `MAIL_*`；设置 `REDIS_PASSWORD` 后 Redis 容器自动启用 `--requirepass`（健康检查与后端 `SPRING_DATA_REDIS_PASSWORD` 同步生效），安全开关 `COOKIE_SECURE` / `REQUIRE_HTTPS` / `CSRF_ENABLED` 可经 `.env` 一键开启（详见 `.env.example` 注释）。

> ⚠️ 早期交付文档中提到的 `docker build -t ai-course-platform .` + 单容器 `docker run -p 8080:8080 -p 5173:5173` 方式已废弃，请以本文件的 `docker-compose.yml` 为准。
