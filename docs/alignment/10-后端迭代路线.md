# 后端迭代路线

> 编制时间：2026-11-04  
> 范围：`backend/`、`python-services/`、数据库迁移、部署/CI 中由后端负责的部分。  
> 任务状态唯一来源仍为 [后端待办项](../后端待办项.md)；本文定义阶段顺序、集成接口与准入/出口，不复制全部 B-13 明细。产品边界以 [决策对齐总表](01-决策对齐总表.md) 和 PRD 为准。

## 1. 目标与边界

交付可支撑《计算机网络》单课闭环的服务端：身份与权限可靠；图谱可查询；课程问答有知识依据及诚实降级；错题诊断与学习路径能映射到图谱；资料、练习/考试基本链路可供前端调用。外围治理、监考、查重、微调等按当前范围冻结或列为 NICE，不以控制器数量作为完成度。

后端向前端交付稳定、版本化、可测试的 HTTP 契约。前端不得依赖 Java/Python 内部类、数据库结构或服务间私有协议。

## 2. 路线与出口

### B0：稳定基线与契约清点（立即）

- 以 `docs/系统架构设计.md` API/集成契约章节、Java Controller/DTO/VO、Python `ContractPaths` 与契约测试交叉核对现状。
- 每个前端必需流程给出契约卡：方法/路径、角色权限、请求字段、成功响应、分页/空态、错误语义、来源字段、幂等/重试约束、对应契约测试。
- 逐条确认 B-13：标注可实施、待产品裁定、明确不提供；缺口不得由前端假数据掩盖。
- 修复审计/验证流程对当前文件结构的路径假设；确保后端单测、契约测试和引擎测试在支持环境可重放。记录本机/CI 环境阻塞，不把历史读数冒充当前通过。

**出口**：冻结本轮联调 API 清单；未决契约有负责人和决定期限；契约测试能独立运行。

### B1：核心服务闭环（红线优先）

1. **知识图谱**：确认《计算机网络》课程图谱数据、课程范围过滤、节点/关系/子图/多跳规划接口；返回稳定 ID、label、relation 与可解释路径。`mode` 清楚区分 `ENGINE`、`LOCAL`、`UNAVAILABLE`。
2. **问答防幻觉**：删除无来源纯 LLM 成功回退；检索无结果、索引缺失、KG/RAG 服务异常均返回显式不可用/未知语义。将文档检索和图谱上下文纳入回答流程，sources 能区分文档与图谱节点/关系。
3. **薄弱诊断与路径**：修复错题到知识点的身份映射；所有输出基于答题/错题与知识点掌握度；不可映射时返回可观测降级状态，不用固定扣分公式伪造精度；路径结果带节点、顺序、理由。
4. **资料/作业考试支撑**：按 PRD 的单课必要范围核实教师维护资料/索引、学生查询、布置/作答/批阅/成绩接口，状态与权限语义一致；外围功能继续冻结。

**出口**：端点契约测试通过；Java↔Python 集成测试覆盖正常、空资料、下游不可用、开关关闭；回答来源和降级行为有断言；诊断路径有映射与不可映射测试。

### B2：前后端联调与一致性

- 发布可供前端接入的 OpenAPI/契约清单和本地环境配置说明；每个契约变更同时更新 Java/Python 测试及架构文档。
- 提供脱敏的稳定测试夹具：固定课程、学生/教师/管理员角色、知识点与语料标识；不得依赖未说明的本机数据库状态。
- 统一分页信封、时间/ID 格式、空列表与错误格式；AI 回答明确 `answer/status/sources/gen_mode` 语义（以最终契约命名为准）。
- 配置 CORS、CSRF、Cookie/JWT、上传限制和健康探针，使浏览器经前端代理/网关可真实调用。
- 联调期间先冻结接口字段；必须变更时走契约版本/兼容策略，通知前端并同步 mock 与断言。

**出口**：前端关键页面不依赖临时 mock 即可跑主流程；关键请求/响应与权限由集成测试覆盖；联调阻塞登记到具体端点与责任人。

### B3：可重复交付与运行保障

- 依 PRD Phase 1 决定生产部署边界；若目标仍是生产部署，补齐 KG/RAG 镜像或等价编排、前端构建参数接线、密钥注入、TLS/反代、健康检查、备份/恢复和回滚。
- 修复并稳定 Java 覆盖率门、Python 引擎测试环境与 CI 主干证据；增加 Java↔Python 核心集成门禁。
- 完成资源型接口对象级授权矩阵、敏感数据脱敏、缓存/N+1/慢 SQL 风险的高优先项；建立目标环境容量测试口径，不用本机吞吐承诺生产 SLA。
- 固化种子数据、RAG 语料与图谱初始化步骤，保证新环境可重复构建。

**出口**：空白目标环境能按文档部署；健康/降级状态可观察；备份恢复与回滚验证留有可重放证据；CI 对主干提交实际执行。

### B4：扩展（核心交付后）

先抽象课程级数据与知识导入/校验流程，再试点第二门课程；保持现有契约向后兼容。多租户、计费、LoRA、非核心治理等不进入单课交付关键路径，另立需求与容量评估。

## 3. 必须提供给前端的契约包

每次迭代至少更新以下内容：

| 契约域 | 前端需要的事实 | 后端交付证据 |
| --- | --- | --- |
| 登录/权限 | 登录态、角色、刷新/登出、401/403 行为 | Controller/API 文档、Security 测试、浏览器跨域/CSRF配置 |
| 课程/资料 | 课程 ID、资源上传/索引状态、检索范围 | DTO/VO、契约测试、失败与空态样例 |
| 图谱 | 节点/边 ID、课程过滤、路径顺序/理由、mode | KG 契约测试、集成样例 |
| AI 问答 | 请求限额、回答状态、来源类型/ID/标题/片段、gen_mode | RAG 契约测试、无来源/服务故障集成测试 |
| 诊断/路径 | 学生范围、知识点 ID、掌握度定义、路径理由、降级状态 | Service 测试、端到端映射样例 |
| 作业/考试/成绩 | 状态机、幂等、截止时间、附件、权限 | API 契约、数据库迁移、集成测试 |

契约定义位置：`docs/系统架构设计.md`；Python 引擎另以各服务 `ContractPaths` 和 contract tests 为实现约束。改契约必须在实现 PR 前/同批先更新文档与测试。

## 4. 双线协作规则

1. 后端先交契约卡和可运行的 mock 响应样例；前端可以并行开发，但 mock 必须来自契约，不另造字段。
2. 后端实现期间保持字段兼容；不可兼容变更须提供迁移窗口和旧字段移除条件。
3. 前端完成页面状态后，双方以同一测试夹具联调：成功、空态、权限拒绝、校验错误、服务不可用至少各一例。
4. 某条前端依赖端点尚未实现时，标记 `blocked-by B-...`；不能用假数据把状态改为完成。若决定不提供，需同步产品文档、导航与用户提示。
5. 里程碑只有前端/后端各自门禁通过且联合端到端流程通过才关闭。

## 5. 当前高优先级缺口

- `RAG_ENABLED`/`KG_ENABLED` 默认关闭与 `AiRagComponent` 纯 LLM 回退不满足防幻觉红线。
- 图谱尚未进入 RAG 回答主路径；诊断存在名称不匹配时固定公式回退。
- Python 服务缺少容器交付件，Compose 服务块注释；生产部署文档仍标记未实施。
- B-13 尚有待实施/待裁定契约缺口；详细状态只维护在后端待办 §2.1。
- 当前环境后端/Python 测试未形成新一轮通过证据；修复环境问题后应重跑，不将历史读数代替当前状态。

## 6. 任务状态与汇报

每项按 `未开始 / 进行中 / 受阻 / 已完成 / 明确不做` 记录。已完成必须同时附代码入口、测试命令和结果；受阻要指明对应前端 F 项、缺失契约或环境条件。任务编号沿用 `B-Mx-yy` 或后端待办原编号，不重复创建平行台账。
