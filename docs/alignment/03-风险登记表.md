# 项目风险登记表

## 一、文档性质

本文档登记本项目已识别的关键风险，按杀伤力排序，并给出触发条件与缓解动作，独立成篇，供团队在周会与里程碑评审中对照核销。

## 二、风险分级定义

- **高**：一旦发生直接导致项目不可交付或红线失守。
- **中**：显著拖慢进度或削弱差异化，但可缓解。
- **低**：影响有限，可接受或易规避。
