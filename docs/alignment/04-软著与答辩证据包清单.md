# 软著与答辩证据包清单

## 一、文档性质

本文档定义软件著作权（软著）申请与项目答辩所需的证据包内容、采集时机与留存要求，独立成篇。核心原则：**证据包自开发起顺手收集，禁止结题前一个月补造**——运行痕迹一旦错过即不可复原。

## 二、软著法定材料（通用要求）

| 材料 | 内容 | 采集时机 |
| --- | --- | --- |
| 源代码 | 前后各 30 页（含必要注释与模块结构） | 开发全程留痕，M5 前定稿 |
| 设计说明书 | 系统架构、模块划分、关键流程、数据库设计 | 随架构稳定同步撰写 |
| 运行环境说明 | 依赖、部署步骤、配置（含 Neo4j / Milvus / 模型） | 部署可复现即记录 |
| 运行截图 | 三端主流程、图谱可视化、问答界面 | 每里程碑留存 |

## 三、差异化佐证证据（应对 R10）

| 证据 | 说明 | 采集时机 |
| --- | --- | --- |
| 图谱构建流程日志 / 截图 | 证明图谱真实存在、由教材抽取，非 prompt 假装 | M1 起留存 |
| 问答命中知识库真实案例 | 同题下本系统 vs ChatGPT 的答案对比，体现「更贴合学业」 | M3 真人测试同期 |
| 诊断基于图谱演示记录 | 答题记录 → 图谱节点 → 薄弱标定的端到端录屏 | M2 起留存 |
| 防幻觉兜底案例 | 离题 / 超纲问题下「如实说不知道」的响应记录 | M3 起留存 |
| 真人试用报告 | 邀请同学试用，记录答疑质量与满意度 | M3 |

## 四、答辩演示预案

- **形式**：现场实操（非预录），题库标准且覆盖核心知识点。
- **兜底**：准备与课程无关的问题现场测试「答不出即说明」机制，证明防幻觉真实有效。
- **叙事**：以「显式知识骨架 vs 隐式参数知识」一句话差异化主张统领演示。

## 五、提交节奏

- 软著于 M5（2027-03，快结题时）提交，确保规划功能已完成、系统达生产级。
- 答辩材料（PPT / 演示脚本 / 证据册）于结题前 1 个月（2027-03 起）集中编排。

## 六、文档标准声明

本文档遵循学术性、准确性、简洁性、独立性原则，作为初稿交付，不含修订痕迹。
