# 项目决策对齐总表

## 一、文档性质

本文档为「基于知识图谱 + LLM 的 AI 助教系统」（校级大学生创新创业训练项目，以下简称「本项目」）的全局决策基线。全文独立成篇，不依赖任何会话上下文，供团队成员、指导教师、评审子 Agent 在开发、验收与答辩阶段统一对照使用。

## 二、核心定位

- **项目本质**：基于知识图谱 + 大语言模型（LLM）的 AI 助教系统，定位于高校课程学习的智能化辅助。
- **一句话使命**：让学生学得更轻松，聚焦「学不会」这一刚性痛点，以体系化手段提供可溯源的学习支持。
- **愿景边界**：短期交付「计算机网络」单门课程垂直利器；中期扩展至多课程并申请软件著作权（软著）；长期（不设强制时间线）设想上位替代现有泛在学习平台（学习通 / 泛雅）。

## 四、三条不可破红线

1. **知识图谱构建流程必须真实存在**，不得用 prompt 假装。
2. **学生薄弱点诊断必须基于图谱**，而非随机或规则写死。
3. **AI 问答须结合知识库精准回答**，不得随意发挥、须防幻觉，且具备「答不出即如实说明」的兜底。

## 五、一句话差异化主张

本系统依托知识图谱承载结构化教学知识并提供可溯源的知识关联约束，LLM 配备课程知识库，回答更贴合实际学业；相较之下，学习通 AI 与通用 ChatGPT 属依赖模型内部隐式参数知识的纯生成式系统，缺少显式、可控的知识骨架。
