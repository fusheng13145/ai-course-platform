> **2026-11-19 压缩版**：保留产品定位、用户与范围、功能需求、验收指标、生产准入门槛和当前未达标项。原 14 维度 140 项的逐条明细、历史路线图与云端对照长表见 commit `7cf88754`；当前任务状态只看 [`当前状态与待办.md`](./当前状态与待办.md)。

## 1. 定位

**把“教、学、练、考、评、析”收进一个平台，并用 AI 把教师最耗时的三件事（出题、批改、学情分析）变成可审核的建议，而不是不可控的自动决策。**

### 1.1 用户与痛点

| 用户 | 场景 | 痛点 | 产品回应 |
| --- | --- | --- | --- |
| 学生 | 课前课后自学、作业、考试、查漏 | 不知道学什么、错了不知为什么、反馈慢 | 学习路径、错题本、AI 问答、即时成绩与评语 |
| 教师 | 建课、布置任务、组卷、批阅、看学情 | 重复劳动多、批阅量大、学情靠感觉 | 自动组卷、AI 预批（教师确认）、多维分析 |
| 管理员 | 账号、分班、权限、审核、用量 | 权限边界不清、内容风险、AI 成本不可见 | RBAC、审核台、按课程 AI 用量 |
| 运维 | 部署、监控、审计、容量、合规 | 系统黑盒、故障不可观测、数据不可控 | 监控告警、审计、备份恢复、降级语义 |

### 1.2 差异化

- **单课做深**：以《计算机网络》为样例，把课程—章节—任务/考试—成绩—图谱—RAG 打通。
- **AI 可审核**：AI 只给建议分/建议文本，教师确认后才生效；失败 503，不伪造成功。
- **图谱可溯源**：知识点与关系来自课程语料与证据；不拿 prompt 假装图谱。
- **防幻觉**：问答基于课程知识库；不确定时如实说不知道。

### 1.3 阶段

| 阶段 | 范围 |
| --- | --- |
| Phase 1 | **单租户生产系统**；≥10,000 注册用户设计容量；不引入多租户 |
| Phase 2 | 多租户 SaaS（`tenant_id`、隔离、配额/计费）；Phase 1 只保留扩展点 |
| 当前 | 结题材料（三指标、数据集、报告、论文、软著）优先；工程尾量与前端体验并行 |

## 3. 角色

| 角色 | 代码 | 核心权限 |
| --- | --- | --- |
| 学生 | `STUDENT` | 选课、学习、提交、考试、看成绩、问 AI |
| 教师 | `TEACHER` | 建课、内容、组卷、批阅、学情、课程图谱/语料 |
| 管理员 | `ADMIN` | 用户/班级/权限、课程治理、审核、日志、AI 用量 |

权限模型：方法级 `@PreAuthorize` + 对象级 ACL；前端只控制入口可见性；角色变更即时生效。

## 4. 功能需求

### 4.1 认证与账号

登录、注册、找回密码、刷新令牌、退出、会话保活、密码策略（8–32 位复杂度）、失败锁定（5 次/15 分钟，按 IP+账号）、登录限流（默认 10 次/60 秒/IP）、强制下线、在线会话。

### 4.2 课程与教学

- 课程库、开课任务、教学班三层模型；课程创建/编辑/停启用、目录与封面。
- 章节树、选课/退课、成员与行政班、课程通知。
- 资源上传、版本、回滚、下载；教师侧 >50MB 走分片上传。
- 课程看板：成员、任务、成绩、资源、讨论概览。

### 4.3 任务、试卷与考试

- **任务**：发布、截止、延期、文本 + 多附件提交、退回重做。
- **试卷**：手动选题、自动组卷、总分校验、发布/草稿、统计、题目回显。
- **考试**：会话、倒计时、自动保存、超时交卷重试、强制交卷、监考与风险事件、客观题自动判分、主观题 AI 预批 + 教师确认。
- **批阅**：待批阅列表 → 逐份批阅 → 打分/评语/退回；AI 建议分只回填，不直接改分。
- **学生端**：任务/试卷提交入口、成绩与评语、错题本。

### 4.4 成绩与学情

成绩方案、成绩项录入、总评计算、课程成绩分布、班级/课程/学生多维分析、学习路径、薄弱点分析、AI 学习建议、学习时长与进度。

**学业档案**：跨课程成绩单、学情报告、学习路径；成绩单为打印版，电子印章未实现。

### 4.5 知识图谱与知识库

知识点 CRUD、关系维护、课程级图谱、力导向可视化、前置/后继路径、AI 抽取、知识库文档上传与 RAG 检索、图谱同步。KG 不可达时后端 BFS 兜底并标注降级。

**能力边界**：IPA 能真实产点；IREM 五类判定质量不足，**不得宣称已实现有效 IREM**。

### 4.6 AI 能力

| 能力 | 入口 | 链路 | 降级 |
| --- | --- | --- | --- |
| 智能问答 | AI 助教 | RAG 8002 检索 + LLM 生成，SSE | 503 / 纯 LLM / 抽取式 |
| AI 出题 | 题库、试卷 | LLM 生成 JSON → 题目落库 | 503 |
| AI 批改 | 提交批阅 | LLM 建议分 + 评语 → 教师采纳 | 503 |
| 学习建议/学情 | 学生分析页 | LLM 生成文本 | 503 |
| 知识点抽取 | 知识图谱 | LLM 抽取 → KG 写入 | 503 |
| LoRA 微调 | 管理端/引擎 | 8003 PEFT 训练、权重导出、adapter 推理 | 503 |

统一语义：非空字符串 = 真实生成；`null` = Key 未配置；失败 = `LLMUnavailableException` → 503；4xx 不重试；**禁止失败仍 200 + 兜底文案**。

### 4.7 互动与协作

讨论区、签到、投票、课堂互动记录、通知与提醒、站内信/铃铛未读、全局搜索。

### 4.8 管理治理

用户/班级/权限、课程库与开课任务、内容审核、AI 用量、系统日志、健康检查、备份恢复入口；管理端 7 分区、23 路径、13 图标。

### 4.9 导航与页面

- 学生外层：我的课程 / 系统消息 / 学业档案 / 工作台。
- 教师外层：我的课程 / 系统消息 / 工作台。
- 作业、课件、讨论、成绩、考试、知识图谱、AI 助教、AI 语料全部在课程之下；在线监考并入考试；AI 语料并入 AI 助教。
- 一页 = `PageHead(title)` + 动作 + 内容；页头无副标题/kicker；空态一行、错误态一行 + 重试。

### 4.10 新人引导

首次登录引导、重看入口、真实洞形高亮、按账号保存完成态；不做跨设备承诺。

## 5. 核心流程

1. **建课**：课程库 → 开课任务 → 教学班 → 章节 → 资源/任务/试卷。
2. **学习**：学生选课 → 看章节/资源 → 做任务 → 提交 → 看反馈。
3. **考试**：教师组卷 → 发布 → 学生会话作答 → 自动保存/交卷 → 自动判分 → 主观题批阅。
4. **成绩**：成绩方案 → 成绩项 → 总评 → 分布/学情 → 学习建议。
5. **AI 问答**：问题 → RAG 检索 → 重排 → LLM 生成 → 来源展示；失败降级并标注。
6. **图谱**：语料 → IPA 抽点 → 人工抽检 → 关系候选 → 图查询/路径。

## 9. 生产准入门槛

| 域 | 必须满足 |
