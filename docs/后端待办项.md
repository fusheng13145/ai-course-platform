## 4. 每批必须遵守

- **先建改前证据**：需要行为/性能/视觉对比的，先留改前读数。
- **同批改测试**：修复真实缺陷必须补测试锁住；不为凑覆盖率写无意义断言。
- **契约连带**：改接口必须同时改 Java/Python 两侧、契约测试与文档；只改一侧等于留到运行期爆炸。
- **迁移只前向**：已应用 Flyway 校验和冻结；不改历史 SQL，新增迁移号并同步契约清单。
- **本机读数边界**：本机只跑 `-DskipITs`；IT、Trivy、完整 e2e 由 CI/目标环境取数，不能拼接引用。
- **密钥**：不打印、不粘贴、不写日志；只引 `audit-stats.py` 的派生结论。
- **文档**：结构计数只写 `项目手册 §8`，测试读数只写 `测试文档 §2`，剩余任务只写 `当前状态与待办`。
