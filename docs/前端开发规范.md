# 前端开发规范

> **文档定位**：本文件规定前端（Vue 3 + TypeScript + Vite）的目录、组件、状态、请求、样式、可访问性、测试与构建约定，是页面开发与代码评审的落地依据。系统结构与技术决策见 [系统架构设计.md](系统架构设计.md)；后端接口约定见 [后端开发规范.md](后端开发规范.md)；质量门读数见 [测试文档.md](测试文档.md)。
>
> **适用范围**：`frontend/src/**`、`frontend/e2e/**`、`frontend/scripts/**`、`frontend/*.ts`。历史 `lang="js"` 组件在改动时逐步迁移到 TypeScript，不要求一次性重写。

## 3. 单文件组件（SFC）

### 3.1 结构顺序

```vue
<template>
  <!-- 模板 -->
</template>

<script setup lang="ts">
// 逻辑
</script>

<style scoped>
/* 仅本组件样式 */
</style>
```

- 新组件一律 `<script setup lang="ts">`；`<script setup>` 不允许 `this`。
- 组件顶层只放：`defineOptions`、`props`、`emits`、`computed`、生命周期、方法；复杂逻辑抽 composable。
- `defineProps` / `defineEmits` 必须显式声明；禁止依赖 `$attrs` 隐式传参作为主要契约。
- 需要默认值的 prop 用 `withDefaults` 或运行时 `default`（如 `V2Modal` 的 `width: '720px'`、`closeOnBackdrop: true`）；Boolean prop 缺省且需要"未传 ≠ false"时显式 `default: undefined`。
- 不要用 Vue 保留名做 prop（`style`、`class`、`key`、`ref`）；需要样式变体时用 `variant`。
- 禁止直接修改 prop；需要派生值用 `computed`，需要双向绑定用 `v-model` + emit。
- `v-html` 必须配 DOMPurify 清洗；无清洗不得使用（ESLint 会警告）。
- `console.log/info/debug` 禁止提交（允许 `console.error/warn`）；调试代码删除或加 `eslint-disable` 并说明。

### 3.2 事件与 v-model

- 表单类组件默认 `modelValue` + `update:modelValue`；关闭类事件同时提供 `close` / `closed`（离场后）。
- 事件名用小驼峰（模板中用 kebab-case 监听）。
- 子组件不得直接调用父组件方法；通过事件或 provide/inject（限壳层）通信。
- 同一事件不要同时向父级转发两条语义重复的腿：`V2Modal` 关闭时发 `update:open(false)`（给 `v-model:open`）与 `close`（给动作回调）两条即止，页面不再造第三条。

### 3.3 组件边界

- 页面只编排：取数、状态、布局、子组件组合；可复用逻辑下沉 composable，可复用视图下沉组件。
- 单文件建议 ≤ 500 行；超过按“列表 / 表单 / 弹层 / 图表”拆分。
- 业务组件不得反向依赖页面；`src/v2/components/` 不 import `src/v2/views/`。
- 浮层只用 §4.1 列出的自研原语；全仓不得出现 `el-*` 标签或 `element-plus` 引用（守卫 `noElementPlus.test.ts` 当前 0 命中，且带阴性对照）。

## 4. UI 原语与浮层

### 4.1 可用原语（`src/v2/components/`）

| 组件 | 用途 | 关键契约 |
| --- | --- | --- |
| `V2Modal` | 对话框 | props `open`／`title`／`kicker`／`width`／`closeOnBackdrop`；emits `update:open` 与 `close`；默认 Teleport 到 body；`role="dialog"` + `aria-modal`；焦点陷阱、滚动锁引用计数、Esc、`announce()` 播报 |
| `V2ConfirmHost` + `composables/v2Confirm.ts` | 危险操作二次确认 | 页面统一调 `utils/dangerConfirm.ts` 的 `confirmDanger()`，文案由 `utils/dangerMessage.ts` 生成；取消／关闭一律 `resolve(false)`，不 reject |
| `V2NotifDrawer` | 通知抽屉（壳层唯一抽屉） | 开合与未读数由 `composables/ui.ts` 管；列表来自真实接口，失败显示错误态，不得渲染成"暂无通知" |
| `V2Toasts` | 轻量反馈 | `v2Toast(message, tone)`；容器 `aria-live="polite"`；tone＝`info`／`ok`／`warn`／`danger` |
| `V2Palette` | 全局搜索（`Ctrl/⌘+K`） | 只在壳层挂载，页面不自建第二套命令面板 |
| `V2Table` | 记录列表 | 传入 `nav.ts` 定义的 `V2Table` 结构 + `kicker`；单元格为字符串或 `{ text, chip }`，富文本经 `sanitizeTableCellHtml` |
| `V2Stat`／`V2Sparkline`／`V2Sprite` | 指标卡与内联图形 | 数值与图形只来自接口读数；缺数显 `—`，不得画示例曲线 |
| `V2Icon` | 图标 | 名称取自内置集合；装饰图标 `aria-hidden="true"`，图标按钮必须有 `aria-label` |
| `V2PageHead`／`V2Topbar`／`V2Sidebar` | 页头与壳层导航 | 只在 `V2Shell` 内装配；页面不得再造导航或固定条 |

### 4.2 浮层规则

- 可见性受控：用 `:open` + `@update:open`（或 `v-model:open`）；关闭由组件发事件，页面不要再造第二条关闭腿。
- 浮层一律 Teleport 到 body（组件已内置），避免被父级 `transform`／`filter` 困住层叠上下文。
- 层叠档位目前是 `styles/record.css` 里的固定值：modal `2400`／palette `220`／notif `210`；新增浮层先对齐档位，不要就地写更大的数。
- 焦点与滚动统一走 `composables/useOverlayA11y.ts`（`trapFocus`／`lockViewportScroll` 引用计数／`announce`）；自研浮层必须复用，不得各写一套。
- 不要给 Teleport 根挂指令（如 `v-loading`）：根不是普通元素节点，指令无处安放；在浮层内部包一层容器。
- 删除／危险操作必须有二次确认；确认文案写清对象与后果，禁止"确定/取消"式模糊确认。

## 5. 路由与布局

- 路由 `meta` 必填：`requiresAuth`、`title`；需要角色分流的再加 `role`，v2 页面另带 `v2page`（导航登记）或 `v2error`（错误页档）。
- 守卫只有一份实现：`src/router/guard.ts` 的 `installRouterGuard(router, resolvePaths)`，由 `v2/router.ts` 传入本端落点。顺序＝登录态 → 角色 → 目标路由；未登录去 `/login`，角色不符去对应端首页，后端不可达去 `/503`，未知路径 `/404`。
- `/503`、`/403`、`/404` 与登录／注册／法务页必须 `requiresAuth: false`，否则守卫会再次发起会话探针形成轮询环。
- 页面切换时取消未完成请求（`cancelAllPendingRequests`），避免旧响应覆盖新页面；重试路径不得复用已中止的 `signal`。
- 壳层只有 `src/v2/V2Shell.vue` 一套；导航结构与页面登记集中在 `v2/nav.ts`，"提不提供某页"由 `v2/notProvided.ts` 处置（`provided`／`hidden`／`unavailable`），页面不重复写导航。
- 路由懒加载：页面级 `() => import(...)`；首屏只加载登录/壳层必要模块。

## 6. 状态管理

- 全局 store 只有 `auth`；其他状态放页面/composable。
- 权限判定以服务端 `/auth/permissions` 响应为准；本地缓存只用于渲染，`permissionsLoaded` 只由真实响应置位，不得由 localStorage 恢复。
- 前端角色只用于显示与路由分流，**不作为授权凭据**；按钮权限同样 fail-closed。
- 不在模块顶层保存可变单例（跨页泄漏）；需要共享时用 store 或显式参数。
- 不把令牌写入 localStorage/sessionStorage（令牌在 HttpOnly Cookie）；只持久化非敏感的用户展示信息。

## 7. 请求层

### 7.1 分层

```text
页面 / composable
  → api/<域>.ts（命名导出 + default 对象）
  → api/request.ts（axios 实例）
      baseURL `/api`、withCredentials、XSRF-TOKEN/X-XSRF-TOKEN
      请求取消、重试、统一错误提示、信封解包
```

- 页面不得直接 `import axios`；一律经 `api/` 模块。
- API 模块只做 URL/参数/方法封装，不写业务状态与提示。
- 每个模块同时提供命名导出与 default 对象，保持调用方两种写法兼容。
- 路径必须与后端一致；新增/修改后跑 `npm run lint:api-refs`。

### 7.2 错误处理

- 统一错误文案在 `api/request.ts` + `utils/requestError.ts`，页面不拼接 axios 原始英文错误。
- 401：清理登录态并跳转登录；403/404/429/500/503 按统一中文提示。
- 网络错误与 502/503/504 自动重试一次；非幂等方法不得盲目重试。
- 页面必须显式处理三态：加载中、空数据、加载失败；**失败不得渲染成“暂无数据”**。
- 列表失败用 `useListFeedback` 统一错误态与重试；弹窗失败保留用户输入。
- 不在 catch 中静默吞错；至少记录并给用户可操作提示。

### 7.3 表单

- 提交态由所在页面/composable 自持（如 `submitting` ref）：按钮 `:disabled` 绑定它、文案切"提交中…"，并在 `finally` 复位——旧端的 `useFormSubmit` 已随旧端下线，不再有共享封装。
- 校验规则就近声明；跨字段校验在提交前统一执行；失败要把焦点／滚动定位到首个错误控件。
- 成功后关闭浮层并刷新列表；失败保持浮层打开并保留用户输入。
- 危险操作二次确认统一走 `utils/dangerConfirm.ts` 的 `confirmDanger()`；确认后仍需处理失败提示与回滚路径。

### 7.4 分页

- 服务端分页用于数据量无上限的列表（默认选择）。
- `useClientPagination` 只用于已经一次性取全的数据（如课程名册、成绩簇）；不得用它掩盖未分页的后端接口。
- 分页参数统一 `page`（从 1 开始）/`size`；与后端 `PagedResponse` 对齐。
- 需要“全量导出/统计”时使用显式的 `getAllXxx` 分页遍历，不把 `size` 调到超大。

## 8. 样式与设计令牌

### 8.1 令牌

| 族 | 令牌 | 说明 |
| --- | --- | --- |
| 表面／文字／线 | `--bg`、`--surface`／`--surface-2`／`--surface-3`、`--ink`／`--ink-2`…`--ink-4`、`--line`／`--line-strong` | 明暗两套在 `record.css` 分层覆写 |
| 品牌与语义色 | `--accent`（＋`--accent-ink`／`--accent-strong`／`--accent-soft`／`--accent-2`）、`--ok`／`--warn`／`--danger`／`--info` 各带 `-soft`、`--tone-1…5` | 状态色成对使用（实心＋soft 底） |
| 字体 | `--font-body`／`--font-display`／`--font-mono` | — |
| 圆角 | `--r-card`、`--r-ctl`、`--r-chip`、`--r-xs`／`--r-sm`／`--r-md`／`--r-lg`／`--r-bar`／`--r-circle` | 暗色档把 card 16→12、ctl 10→8 |
| 阴影 | `--sh-card`、`--sh-pop` | 暗色卡面不投影，浮层保留 |
| 几何 | `--nav-w`、`--header-h`、`--status-h` | 窄屏在媒体查询里改档，不在页面写死 |
| 动效 | `--ease`、`--ease-spring`、`--t-xslow` | 禁用动画走 `prefers-reduced-motion` |
| 焦点 | `--focus` | 不得移除 `:focus-visible` 轮廓 |

**间距没有令牌族**：现状是 `gap`／`padding` 的字面值。新增间距沿用同区块既有档位，**不要引用 `--ac-spacing-*` 这类已随旧端作废的令牌名**。

规则：

- 颜色、圆角、阴影优先用令牌；新增硬编码值前先确认令牌是否缺失，缺失则补令牌而不是就地写死。
- 局部样式用 `<style scoped>`；跨页共享类放 `src/v2/styles/`（`record.css` 基础层＋`form`／`auth`／`typography`／`shell-fix`），选择器以 `body[data-app="v2"]` 作用域起头。已无组件库覆写层，`!important` 全 v2 样式共 8 处，新增必须写明压过什么。
- 深色/浅色必须同时验证；不得只在一个主题下可读。
- 禁止用颜色作为唯一状态信号（配合文字/图标）。
- 响应式：以 1440×900 为设计基准，窄屏至少保证 375 宽可用；浮层宽度用 `width` prop 或 min/max，不写死超出视口的 px。
- 不使用 `position: fixed` 的页面级元素覆盖壳层导航；需要时用浮层原语。

### 8.2 可访问性

- 图标按钮必须有 `aria-label`；装饰图标 `aria-hidden="true"`。
- 表单控件必须有 label 或 `aria-label`；错误提示与控件关联。
- 键盘可达：可点击元素优先用 `<button>`/`<a>`；自定义控件支持 Enter/Space。
- 焦点可见：不得全局移除 `:focus-visible` 轮廓；弹层内焦点陷阱、关闭后归还。
- 状态变化用 `aria-live` 播报（浮层与异步结果走 `useOverlayA11y.ts` 的 `announce()`，轻量反馈走 `V2Toasts` 的 `aria-live="polite"` 容器）；加载态用 `aria-busy`。
- 文本对比度 ≥ 4.5:1（大字号 ≥ 3:1）；不得仅靠 hover 暴露关键操作。
- 动画尊重 `prefers-reduced-motion`；自动播放/轮播可暂停。

## 9. 性能

- 路由级懒加载；大组件/图表/导出库动态 `import()`。
- 列表渲染超过 ~100 行时考虑虚拟滚动或分页；不得无界渲染全量数据。
- 图片使用适当尺寸与懒加载；不在模板中做重计算，放 `computed`。
- 避免在 `watch` 中做深度遍历大对象；必要时用 `watchEffect` + 明确依赖。
- 新增第三方库前先看 `npm run build && npm run size:gate` 的增量；超预算必须说明理由并调整分块。
- 不把整库引入（如 `import _ from 'lodash'`）；按需导入。
- 图形是内联 SVG（`V2Sparkline`／`V2Sprite`），没有第三方图表实例；但 `requestAnimationFrame`、定时器和 `document`／`window` 监听必须在 `onBeforeUnmount` 移除。

## 10. 测试

### 10.1 单元/组件测试（Vitest）

- 文件放 `__tests__/`，命名 `Xxx.test.ts`；与被测文件同域。
- 使用 `@vue/test-utils` 挂载；断言用户可见行为（文本、角色、事件），不测实现细节。
- 必须覆盖：空态、加载态、错误态、权限拒绝、边界输入。
- 弹层测试注意 Teleport：必要时 `stubs: { teleport: true }` 或挂到 `document.body`；`Transition` 需 `stubs: { transition: false }` 并 mock `requestAnimationFrame`。
- 不 mock 被测组件自身的子组件行为到“只剩快照”；关键交互要真实触发。
- 快照只用于稳定结构，不替代行为断言。

### 10.2 端到端（Playwright）

- 流程 spec 放 `e2e/`，按业务链路命名；选择器优先 `getByRole` / `getByLabel` / 稳定的 `data-testid`，避免依赖样式类与 DOM 层级。
- 前置：后端 8080 就绪、`RATELIMIT_LOGIN_LIMIT=200`、前端 5173；`.auth` 夹具与端口绑定，跨端口需重绑。
- 不写固定 `sleep`；用 `expect(...).toBeVisible()` / `waitFor`。
- 每个 spec 独立登录态，不依赖执行顺序；测试数据可重复创建/清理。
- 新增页面若纳入视觉回归，需同时加锚点、遮罩与基线，不能只加流程用例。

### 10.3 视觉回归

- 配置：`playwright.visual.ts`，1440×900、DPR 1、`reducedMotion: reduce`、冻结时钟；独立端口 5175。
- 基线：5 锚点 × 明暗 = 10 张（`e2e/visual/v2-anchors.spec.ts`）；`threshold: 0`、`maxDiffPixelRatio: 0.0001`。
- 全页：`expandViewportToContent` 扩展到内容实高（封顶 8000），只改高度、不重跑 settle。
- 钉桩：固定接口响应；动态角标必须遮罩；新增动态元素先加遮罩再录基线。
- 变更样式/令牌/结构后，受影响基线全量重录并逐张看图；至少连续两轮通过才算绿。
- 不把视觉证据（截图、report、sequence）当作文档常驻内容。

### 10.4 类型与静态检查

- 新代码必须通过 `vue-tsc`；`typecheck:gate` 棘轮只降不升（当前 0）。
- `any` 仅限无法定型的边界，且加注释说明；优先 `unknown` + 收窄。
- Props/Emits/返回值显式定型；API 响应信封在 api 层定型，页面不重复 `as any`。
- ESLint 0 问题、Prettier 干净；`v-html` 警告必须消除或说明清洗来源。
